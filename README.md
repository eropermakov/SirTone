# SirTone («Сиртон»)

Локальный музыкальный плеер для Windows 10/11 — «офлайн-стриминг» для вашей коллекции: перетащил папку — приложение само скопировало, распознало, разложило по исполнителям и альбомам и включило «Мою волну» с визуализацией под настроение трека.

Студия: **Sir.kov Studio**. Стек: Tauri 2 (Rust) + WebView2 (React/TypeScript).

**Состояние на 15 ноября 2026:** выпускаются предварительные версии для Windows и iPhone. Последние опубликованные — Windows **0.2.5 (прототип 51)** и iPhone **0.2.5**, от 13 ноября. Актуальная объединённая линия — `stage/8-mobile`; новый дизайн этапа 9, обложки и логотип уже в ней. `main` и `stage/7-hardening` пока отражают более ранние состояния.

**В работе:** мобильный порт и проверки на устройствах; суточный тест Windows остаётся открытым. Android — заготовка, не готовое приложение. Точная сводка готового, непроверенного и запланированного — [`docs/STATUS.md`](docs/STATUS.md). Выпуск сборки не означает завершения приёмки этапа.
