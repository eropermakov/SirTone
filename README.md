# SirTone («Сиртон»)

Локальный музыкальный плеер для Windows 10/11 — «офлайн-стриминг» для вашей коллекции: перетащил папку — приложение само скопировало, распознало, разложило по исполнителям и альбомам и включило «Мою волну» с визуализацией под настроение трека.

Студия: **Серков Studio**. Стек: Tauri 2 (Rust) + WebView2 (React/TypeScript).

**Статус:** спецификация 1.3 (с дополнением «Умная волна, сезоны, события и режимы») собрана и обоснована референсами, движок волны спроектирован и проверен прототипом (`spikes/S-17-wave-scoring`), среда разработки установлена; реализация приложения не начата — ждём файл дизайна.
