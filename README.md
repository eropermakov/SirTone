# SirTone («Сиртон»)

Локальный музыкальный плеер для Windows 10/11 — «офлайн-стриминг» для вашей коллекции: перетащил папку — приложение само скопировало, распознало, разложило по исполнителям и альбомам и включило «Мою волну» с визуализацией под настроение трека.

Студия: **Sir.kov Studio**. Стек: Tauri 2 (Rust) + WebView2 (React/TypeScript).

**Статус:** спецификация 1.6 (с дополнением «Умная волна» и дизайном владельца `DESIGN.md`) готова; идёт Этап 0 — каркас приложения (ветка `stage/0-foundation`). Ход этапа — [`docs/reports/stage-0.md`](docs/reports/stage-0.md).
