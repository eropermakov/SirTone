# Сиртон — логотип: краткий гайд

Версия 1.0 · 13 ноября 2026 · Sir.kov Studio

## 1. Идея

Знак — буква «С» (Сиртон), одновременно пластинка и звук: открытое кольцо, короткая дуга-«волна» внутри и бордовая точка в центре. Точка — фирменная точка Sir.kov.

Знак адаптивный: на крупных размерах основной вариант (C3), на малых упрощённый (толще штрих, точка крупнее).

## 2. Состав набора

| Папка | Что внутри |
| --- | --- |
| `svg/symbol/` | Знак: светлая и тёмная тема, малый вариант, одноцветные (чёрный, белый) |
| `svg/lockup/` | Знак с надписью: горизонтальный и вертикальный, рус. и лат., светлый, тёмный, одноцветные |
| `svg/wordmark/` | Только надпись «Сиртон» / «SirTone» |
| `svg/app-icon/` | Основная иконка (чёрная плитка), её малая версия, иконка iPhone 1024. В `alt-burgundy/` дополнительная иконка на бордовом фоне |
| `png/` | Готовые PNG с прозрачным фоном |
| `icons/windows/` | `sirtone.ico` (9 размеров: 16–256), `icon.png` 512. В `alt-burgundy/` то же на бордовом фоне |
| `icons/iphone/` | `AppIcon-1024.png` (сплошной квадрат без скруглений, маску ставит iOS). В `alt-burgundy/` бордовая версия |

## 3. Цвета

Только три: чёрный, белый и бордовый акцент.

| Цвет | HEX | RGB | CMYK (ориентир, сверить пробой) |
| --- | --- | --- | --- |
| Бордовый (accent) | `#650A12` | 101, 10, 18 | 0 / 90 / 82 / 60 |
| Чёрный | `#000000` | 0, 0, 0 | 0 / 0 / 0 / 100 |
| Белый | `#FFFFFF` | 255, 255, 255 | 0 / 0 / 0 / 0 |

Контраст бордового: на светлом `#F4F4F4` 11,9:1, с белым 13,1:1, на чёрном всего 1,6:1.

- Светлая тема: чёрный знак, бордовая точка.
- Тёмная тема: белый знак, бордовая точка. Точка здесь декоративная: на чёрном её плохо видно. Если нужен чёткий акцент, берите одноцветный белый вариант или иконку на бордовом фоне.
- Иконка приложения (основная): чёрная плитка со скруглёнными углами (на iPhone сплошной чёрный квадрат), белый знак, крупная бордовая точка. Знак здесь всегда в плотном начертании, чтобы точка была видна.
- Иконка приложения (дополнительная, `alt-burgundy`): бордовая плитка `#650A12`, белый знак, чёрная точка. Нужна для особых случаев: праздничный релиз, баннеры, страница релиза, где нужен яркий акцент.
- Одноцветные варианты (`mono-black`, `mono-white`): для печати в один цвет, штампа, гравировки, факса.

## 4. Когда какой вариант

| Размер | Вариант |
| --- | --- |
| 44 px и меньше (трей, панель задач, мини-бар, фавикон, вкладки) | Малый (`small`) |
| 48 px и больше | Основной |

В печати: основной знак не меньше 8 мм по высоте, малый от 4 мм.

## 5. Охранное поле и размеры

- Охранное поле: четверть высоты знака со всех сторон. Внутрь ничего не ставим.
- Минимальная ширина горизонтального лого: 120 px (на экране) или 30 мм (печать). Меньше: только знак.
- Знак и надпись не растягиваем, не меняем расстояние между ними, не перекрашиваем в другие цвета.

## 6. Надпись

- Шрифт: Geologica Medium (вес 500), лицензия SIL OFL. Надпись переведена в контуры, шрифт для использования лого не нужен.
- В латинском написании `SirTone` пара «T–o» подтянута вручную.
- Основной вариант: русский «Сиртон». В латинском лого знак читается как «C», а название начинается с S, это осознанный компромисс. Для английской аудитории можно позже сделать отдельный знак.

## 7. Как не надо

- Не заменять бордовый другим цветом и не добавлять градиенты, тени, свечения.
- Не вращать и не зеркалить знак.
- Не ставить основной знак на фон, где кольцо теряется (например, на бордовом: для этого есть иконка `alt-burgundy`).
- Не убирать точку и не менять размер дуги.
- Не использовать основной знак на размерах 44 px и меньше.

## 8. Как поставить в проект

Ничего в папки проекта я не копировал и существующие иконки не трогал. Для Сиртона на ПК:

- `icons/windows/sirtone.ico` → `apps/desktop/src-tauri/icons/icon.ico`
- `icons/windows/icon.png` → `apps/desktop/src-tauri/icons/icon.png`
- Для iPhone: `icons/iphone/AppIcon-1024.png` в каталог ресурсов AppIcon.
- Дополнительная бордовая иконка лежит в `alt-burgundy/` рядом с основной.
- Токены дизайна менять не нужно: используется существующий `accent #650A12`.
- DESIGN.md (раздел 1) требует для знака продукта круг цвета accent с белым символом. Основная иконка Сиртона от этого правила отходит (чёрная плитка). Отклонение стоит записать в журнал решений.
