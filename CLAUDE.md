# SirTone («Сиртон») — правила для Claude Code

Локальный музыкальный плеер для Windows 10/11. Студия: Серков Studio. Стек: **Tauri 2 (Rust-ядро) + WebView2 (React 19/TS/Vite/Tailwind 4/shadcn)**. Версия спецификации: 1.0 (2026-10-15).

## Главные принципы владельца

1. **Не изобретать — копировать.** Для любой фишки сначала смотри `docs/01a_*.md` / `docs/01b_*.md` (как это делают 6+ популярных приложений), потом адаптируй. Нет референса — найди (документация, SDK, справка), запиши в `docs/01*` и только потом реализуй. Особенно: автомикс, визуализация, архитектура.
2. **Спецификация — закон:** `docs/02_TZ.md` (нормативно, ID `FR-*`), детали — `03`…`09`. Отклонение = новая запись в `docs/10_DECISIONS.md`.
3. **Визуал даёт владелец** (шрифты, цвета, макеты, стиль анимаций). Не придумывать дизайн: нейтральный каркас + токены (`docs/06` §1). Ни одного захардкоженного цвета/радиуса/шрифта/длительности в компонентах.
4. **Скорость и лёгкость:** отклик ≤ 400 мс (цель p95 ≤ 100), всё тяжёлое отключаемо пресетами, бюджеты — `docs/08` §1.
5. **Данные пользователя неприкосновенны:** аудио не перекодируется и не изменяется; файловые операции — только через журнал (`fs_journal`); удаление — только в Корзину; нет уверенности в распознавании → «Неизвестные», а не неверная папка.

## Среда и команды (Windows, PowerShell)

Тулчейн на D:\DevTools (Rust 1.99, MSVC, pnpm 12, cargo-deny, cargo-nextest). В «старой» оболочке: `. .\scripts\dev-env.ps1`. После появления каркаса:

```powershell
pnpm install; pnpm tauri dev
cargo nextest run --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all -- --check
cargo deny check
pwsh scripts/check-all.ps1      # всё сразу
```

Диск C: почти полон — кэши и `target` держим на D:. Подробности — `docs/11_DEV_ENV.md`.

## Правила кода

- **Rust:** workspace `crates/sirtone-*` (`core, net, library, recognize, analysis, search, audio, playback, platform, cli`) + `apps/desktop/src-tauri` (единственный, кто знает Tauri). Зависимости между доменными крейтами запрещены (только через трейты `core`). `unwrap()/expect()` — только в тестах и инициализации. Ошибки: `thiserror` в крейтах, `AppError{code,retryable,details}` на границе IPC; **тексты для пользователя формирует UI по коду**.
- **Аудио-поток (RT):** никаких аллокаций, мьютексов, логов, ввода-вывода; метрики — атомики; `catch_unwind` вокруг декодеров. Тяжёлое — в потоке движка; в колбэке только копирование и «поздние» множители.
- **IPC:** типы генерируются из Rust (tauri-specta/ts-rs — ADR D-09); ручные TS-типы IPC запрещены; события асинхронные и батчатся; бинарные потоки — `Channel`; картинки — только через протокол `sirtone-cover://`.
- **БД:** `rusqlite` + миграции вперёд; только параметры/белый список полей; пути относительные корню библиотеки.
- **Фронтенд:** feature-sliced (`docs/03` §3.2); вызовы `invoke` только в `shared/ipc`; **ни одной строки в JSX** (i18n-ключи, русские формы one/few/many); не обновлять CSS-переменные корня чаще 4 Гц (высокочастотное — canvas/WebGL); анимации только `transform/opacity`.
- **Лицензии:** без GPL/AGPL/CC-NC в бинарнике (`docs/08` §3); Essentia-модели не используем; новые зависимости — только через `cargo deny`/реестр `docs/08` §5. Из GPL-проектов (Mixxx, Picard, Navidrome, WaveFlow, bliss) берём **идеи, не код**.
- **Сеть:** только перечисленные хосты, лимитеры (AcoustID ≤ 2/с, MusicBrainz ≤ 0,8/с, описательный User-Agent), мастер-тумблер офлайн; телеметрии нет.

## Работа с git и релизами

- Репозиторий локальный. **Владелец разрешил локальный коммит после каждой готовой задачи (D-36); push — запрещён** до отдельной команды и настройки GitHub (OWN-04). Ветка этапа `stage/N-<имя>`, слияние в `main` после приёмки этапа. Релиз («собрать билд и опубликовать» ✅) — по команде владельца: `scripts/release.ps1` → тег → GitHub Actions (нужны OWN-01/04).
- Идентификатор приложения — `studio.serkov.sirtone` (D-37), менять нельзя.
- Сообщения коммитов — Conventional Commits; не пропускать хуки.

## Чего не делать

Не добавлять функции вне ТЗ (список «вне скоупа» — `docs/02` §23): стриминги, тексты песен, история прослушиваний, синхронизация, профили, бэкап, импорт m3u, перекодирование. Не утверждать, что фича «как у X», если это не записано в `docs/01*` с источником. Не менять настройки безопасности Windows (Defender, SAC) без явного разрешения.
