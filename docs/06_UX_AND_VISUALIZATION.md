«⋯» трека: «Почему этот трек» · «Никогда в волне» (трек/исполнитель) · метки (летний, для сна, хит для всех…) · удалить/переместить/изменить данные/в плейлист/«Волна по этому треку». При затухании сна — крупная кнопка «+15 мин»; в фокусе — кольцо с остатком и фазой.

**«Настроить волну»** — модальное окно: сетка кликабельных чипов по блокам *Настроение · Характер · Язык · Частота · Занятие (+темп) · Обстановка (авто/ручное)* + **(1.3)** *Сезон (авто/лето/осень/зима/весна/не учитывать) · События · Режим (обычная/сон/фокус/для всех) · Знакомое ↔ Неожиданное · Сила влияния (сезон, контекст, события) · Диапазоны энергии и темпа*; «Сбросить»; «Сохранить как свою волну»; живой счётчик «подходит N треков»; «Расширил подбор» — подсказка. Экспертный уровень (раскрывается): веса компонентов, исключения, правила секвенсора, обучение по контекстам с «Сбросить».

**Коллекция (обзор)** — «Вся коллекция: N треков · Ч ч М мин · X ГБ»; плитки: Исполнители / Альбомы / Плейлисты / Жанры / Настроения (каждая с «▶ играть»); виртуализированные сетки.

**Страница плейлиста (гибридный)**
```
 Мои треки…            (1–N)
 ─────────  Рекомендовано из вашей медиатеки  ─────────   ∞ тумблер
 рекомендованный трек                      [＋] [−]
```

**Поиск (оверлей)** — строка; «Лучшее совпадение»; группы Треки/Исполнители/Альбомы/Плейлисты/«По смыслу»; «Играть этот вайб»; пусто → «Похожее из библиотеки».

**Неизвестные** — список с причиной-чипом и подсказками в 1 клик; групповые действия; перетаскивание к исполнителю; «возможно, не музыкальный трек».

**Импорт** — оверлей «Отпустите, чтобы добавить»; панель прогресса (файлов/ГБ/осталось); итоговый отчёт (добавлено · неизвестные · дубли · не добавлено) + «Можно извлекать носитель».

**Дубли** — таблица пар: слева старый, справа новый, класс (точная копия / тот же звук / похожий), действие: *оставить оба · заменить · не добавлять*; «применить ко всем».

**Настройки** — левый список разделов, справа формы; перформанс: *5 карточек пресетов + «Определить автоматически» + раскрывающиеся точечные тумблеры*; Bluetooth: список устройств с «Подключить/Отключить» и «Открыть системные настройки».

**Онбординг (3 шага + тур)** — Тема → Акцент (+ тумблер «Тема по сезону» ✅) → Производительность (+ «Определить») → папка хранилища/язык → интерактивная обучалка (подсветка зон: перетащить музыку, «Моя волна», лайк / «не сейчас», коллекция, поиск); повтор из настроек ✅; анкеты вкуса нет ✅.

**Виджет рабочего стола** — обложка, название/исполнитель, ⏮⏯⏭, прогресс, (по пресету) мини-визуализация; масштаб/прозрачность — в настройках.

**Мини-бар у панели задач** — компактно: обложка-миниатюра, название, ⏮⏯⏭.

## 4. Механизм тем и акцентов

### 4.1. Темы
Тёмная и светлая ✅ (`data-theme`), по умолчанию — **как в системе** (`DESIGN.md` §13, D-62), переключение без перезагрузки. Нейтральные поверхности — токены `DESIGN.md` §3 (`bg-base/layer/raised/flyout/hover/selected`, `inactive`, `border`, `separator`, `text-primary/secondary/tertiary`, `icon`, `focus-ring`, `artwork-placeholder`, `artwork-scrim`, `danger`). Правило **60–30–10** (`DESIGN.md` §2): 60 % нейтраль, 30 % плашки `primary` и обложки, 10 % акцент только на CTA.

### 4.2. Цвет пользователя: 6 токенов (`DESIGN.md` §4)
Компоненты знают только `accent-fill`, `accent-text`, `accent-on`, `primary`, `primary-text`, `on-primary`. **Правило толщины:** тонкое (≤ 4 px, текст, ссылки, прогресс) — `accent-text`; крупное (кнопки, кружки ≥ 22 px) — `accent-fill`. Источники набора (взаимоисключающие, AccentPicker):

| Источник | Как получается набор | Статус |
|---|---|---|
| **Sir.kov** (по умолчанию) и 16 цветов | готовые наборы `DESIGN.md` §4 / §13, проверенные на контраст | ✅ владелец |
| **«Авто» из обложки** | алгоритм `DESIGN.md` §4 (64×64 → OKLab → k-means k=5 → ближайший из 15 хроматических наборов; кэш на альбом); смена — 400 мс, начинается < 100 мс | ✅ владелец |
| **«Свой»** (исходное ТЗ, FR-UI-003) | генератор OKLCH строит 6 токенов из одного цвета: `accent-fill` = цвет, `accent-text` = подгонка L до ≥ 4,5:1 к `bg-base/layer/flyout`, `accent-on` = `#1C1616`/`#F9F6F0` по контрасту, `primary` = глубокий тон того же оттенка (L ≈ 0,25 тёмная / 0,35 светлая), `primary-text` — ≥ 4,5:1 | 🔧 D-58, ✅Q-22 |
| **«Тема по сезону» / событие** (FR-THEME) | тот же генератор из исходного цвета темы | 🔧 D-58 |

Сырые цвета обложки никогда не идут в контролы — только в размытый фон (`DESIGN.md` §4). **Исключение по контрасту:** лайм Sir.kov в светлой теме как заливка — 2,2:1 (сознательно, D-59); текст и прогресс этого набора — `#407A00`.

### 4.3. Палитра (из `DESIGN.md`)
17 наборов × 2 темы — таблица `DESIGN.md` §4 и CSS §13 без изменений; порядок в AccentPicker: «Авто» → Sir.kov → холодные → нейтральные → тёплые → красные; «Свой» — последним (+). Тест T0.9: контраст всех наборов в обеих темах по гарантиям `DESIGN.md` §4.

Акцент на визуализацию — тумблер ✅ (`viz.follow_theme_accent`): смешивание с `accent-fill` текущего набора.

## 5. Поведение и анимации (без стиля)

### 5.1. Правила
1. **Анимация никогда не блокирует ввод** и не удлиняет отклик: потолок реакции 400 мс ✅; длительности — токены `DESIGN.md` §13: `--dur-instant` 100 · `--dur-fast` 150 · `--dur-base` 250 · `--dur-theme` 400 мс, кривая `--ease-out` (decelerate); меню — 150 мс (fade + сдвиг 4 px); «герой» (обложка вырастает в «Сейчас играет») ≤ 400 мс; сезонный дрейф темы — 1–2 с (FR-THEME-003).
2. Только `transform`/`opacity` (+ `filter` на высоких уровнях); без анимации `width/height/top/left`; в списках > 200 элементов — без layout-анимаций.
3. Не обновлять CSS-переменные корня чаще 4 Гц; высокочастотное — только `<canvas>`/WebGL (урок LUMEN).
4. Единый множитель движения `motionScale ∈ {0, 0.5, 1, 1.25, 1.5}` из уровня производительности; `prefers-reduced-motion` ⇒ **только короткие fade ≤ 150 мс**, без сдвигов, масштаба и параллакса (`DESIGN.md` §10, D-61; строка CSS §13 «всё 0,01 мс» заменяется этим правилом).
5. Предпочтительно CSS/WAAPI; библиотека `motion` — для жестов/layout там, где нужна.

### 5.2. События, которые должны быть анимированы (список для дизайна D-6)
Смена трека (обложка, название) · play/пауза · добавление в очередь · перетаскивание (подъём → цель → бросок) · оверлей импорта и прогресс · появление/пропадание в списках · переходы экранов · чипы «Настроить волну» · смена режима визуализации · вход/выход ночного вайба · реакция виджетов на нажатия ✅ · уведомления «понижено автоматически» · **(1.3)** лайк / «не сейчас» / «никогда» · смена сезонной/событийной темы (1,5 с) · появление карточки события · ход кольца фокуса и смена фазы · затухание сна и «+15 мин» · уход полного экрана в чёрный после сна.

## 7. Движок визуализации (технически; копия `01a` §B)

### 7.1. Интерфейс

```ts
interface VizEngine {
  init(host: HTMLElement | HTMLCanvasElement, opts: VizInit): Promise<void>;
  setAudioFrame(f: VizFrame): void;       // 1024×u8 mono/L/R + t_audio_ms + beat_phase + bands[3]
  setVibe(v: VibeVector, palette: Palette): void;   // при смене трека; плавный переход ≤ 3 с
  setQuality(q: VizQuality): void;        // mesh, scale, fps, pixelRatio, fxaa
  pointer(e: {x:number,y:number,kind:'move'|'down'}): void;   // импульсы
  pulse(kind: 'like'|'beat'|'click'): void;
  pause(): void; resume(): void; resize(w:number,h:number): void; dispose(): void;
}
```

Реализации: `WavesEngine` (WebGL2 шейдер), `MilkDropEngine` (Butterchurn), `VideoEngine` (`<video>`).

### 7.2. «Волны» (цветовые; копия Яндекс «Моя волна» + Apple/AMLL) — «Сейчас играет» по `DESIGN.md` §9: фон экрана — активный режим визуализации; на уровне 0 — размытый градиент 2–3 цветов обложки (blur 80–120 px, дрейф 20–30 с)
- Фрагментный шейдер: доменное искажение fBm-шумом (2 прохода), 4-цветная палитра, `u_time` (скорость ∝ arousal), `u_bands` (bass → амплитуда искажения, treble → мелкие блики), `u_beat` (импульс по `beat_phase`/сетке), `u_pointer[]` (белые импульсы курсора/клика), виньетка и зерно.
- **Палитра:** цвет трека из вайба (OKLCH): оттенок по карте (грусть → индиго ~265°, злость → красно-малиновый ~20°, радость/энергия → тёплый 40–60°, спокойствие → бирюзово-зелёный ~170°), хрома ∝ arousal (0,08–0,20), светлота 0,35–0,75; итог `mix_oklab(trackColor, collectionColor, w=0,35)`; при `follow_theme_accent=on` — подмешивание акцента (w=0,25). Минимальный вариант — 2 цвета, без бликов.
- **Цвет коллекции** («Цвет вашей музыки»; не путать с цветом пользователя `DESIGN.md` §4): взвешенное (по `play_count`) среднее палитр треков в OKLab + 2–3 доминирующих кластера (k-means); пересчёт при изменении библиотеки.
- Бюджет: ≤ 25 % iGPU Radeon на 1080p/60 (мощное), ≤ 12 % CPU.

### 7.3. MilkDrop (Butterchurn 2.6.7, MIT; пресеты — `butterchurn-presets` 2.4.7, MIT)
- Данные: `render({audioLevels:{timeByteArray, timeByteArrayL, timeByteArrayR}, elapsedTime})` ✔ (без WebAudio). Конструктор `Visualizer` использует `audioContext` **только** для `AudioProcessor`, который строит граф лишь при наличии контекста ⇒ `createVisualizer(null, canvas, opts)` должен работать (подтверждается в S-04). Опции `deterministic`/`testMode` — для воспроизводимого рендера в индексаторе пресетов.
- **Индекс пресетов (dev-инструмент `tools/preset-indexer`):** для каждого пресета headless-рендер с синтетическим звуком в 3 интенсивностях → дескрипторы (доминирующий оттенок/насыщенность, яркость, движение, реактивность, хаотичность) → `assets/viz/preset-index.json`. Отбор ≈ 300–600 пресетов; вайб → ближайшие по дескрипторам; `CREDITS.md` с авторством (пресеты — работы сообщества).
- Правила (проектM): **30 с** на пресет, мягкий переход **3 с** (`loadPreset(p, 3.0)`), hard-cut выключен; на смену трека — новый пресет по вайбу; `Lock`, `Like/Dislike` (Kodi `RatePreset`) смещают выбор.
- Качество по уровню: mesh 24×18 / 32×24 / 48×36, `textureRatio` 0,5…1, `pixelRatio` ≤ 1 на слабых.

### 7.4. Видео
`<video muted loop playsinline>`; ролики 3–15 с, бесшовный цикл, 1080p, WebM VP9/AV1 (запасной H.264 — на «N»-изданиях Windows без медиа-пакета), каталог `.sirtone/backgrounds/`; привязка к настроениям (теги ролика); пользовательские добавляются перетаскиванием (проверка: кодек, длительность ≤ 60 с, размер ≤ 200 МБ). Права на предзагруженные — ❓OWN-06.

### 7.5. Ночной вайб (иммерсивный режим)
Полный экран окна (F11-аналог) → UI плавно скрывается через N с бездействия, возвращается по движению мыши/клавише; курсор скрывается; `Esc` — выход; `SetThreadExecutionState(ES_DISPLAY_REQUIRED)` пока играет — **кроме активного сон-таймера**: в последние 10 мин запрос снимается, чтобы экран мог погаснуть (`07` §8.1); одиночное название трека еле заметно.

### 7.6. Синхронизация и пауза
Кадры с аудио-временем (`§9` в `04`) уже сдвинуты на задержку вывода; клиент хранит jitter-буфер 2 кадра. Пауза/снижение: окно скрыто (Page Visibility + события окна Tauri), перекрыто, полноэкранное приложение, батарея → переход на уровень ниже или полная пауза (как Wallpaper Engine «Pause/Stop»).

### 7.7. Живые эффекты (FR-FX, `14` §13, спайк S-19)

```ts
interface FxEngine {                     // features/fx, отдельный <canvas> WebGL2 поверх визуализации
  init(canvas: HTMLCanvasElement, q: FxQuality): Promise<void>;   // q: maxParticles, fps, depth, blur
  setState(s: FxState): void;            // тип (snow|rain|fog|storm|clouds|sun_motes|fireflies|leaves|petals|none),
                                         // интенсивность 0..1, ветер {dx, dy}, is_day, плавный переход ≤ 3 с
  setBreath(beatPhase: number, bass: number): void;   // из кадра визуализации; влияет только на закрутку и яркость
  pause(): void; resume(): void; resize(w: number, h: number): void; dispose(): void;
}
```

- Частицы: один буфер `(seed, размер, тип)` на `maxParticles`, позиция = f(seed, t, ветер, дыхание) в вершинном шейдере, `drawArraysInstanced` — ноль работы ЦП на кадр; плотность = число инстансов.
- Туман, тени облаков — полноэкранный шум в ½–¼ разрешения; капли «по стеклу» — нормали + рефракция фона (только уровень ≥ 3).
- Гроза: вспышка — плавный подъём/спад яркости 400 мс, не чаще 1 раза за 10 с (WCAG 2.3.1 — ≤ 3/с); при `prefers-reduced-motion` вспышек нет.
- Показ: только экран «Моя волна» и полноэкранный режим; при уходе с экрана — `dispose()` (освобождение GL-контекста), в трее/свёрнутом — пауза.
- Статичная версия (уровень 1 по тумблеру и reduced-motion): один отрисованный кадр (иней по краям, лежащий снег, капли на стекле) без анимации.
