## V-01. Материалы: плоский / стекло / живой свет (фича 1, п. 2)

**Референсы (6):** Windows 11 Mica/Acrylic (Fluent) ✔ · Apple Liquid Glass (iOS/macOS 26) ✔/○ · Apple Music (iOS 26.4: фон списка треков тонируется под обложку) ○ · Spotify (верх страницы тонируется цветом обложки) ○ · ChatGPT desktop ◌ · Яндекс Музыка ◌.

| Что | Как у референса | Источник | Берём |
|---|---|---|---|
| Запасной цвет | Mica при выключенной прозрачности, экономии батареи, слабом железе, неактивном окне — **сплошной запасной цвет** (`SolidBackgroundFillColorBase`); приложению не нужно угадывать условия, нужен запасной цвет, который хорошо выглядит как однотонный | S127 (Microsoft Learn, Mica; Materials) ✔ | Материал «Плоский» принудительно при: прозрачность выключена, экономия батареи, высококонтрастный режим, слабый пресет, Windows 10; запасная подложка — обычный `bg-base` темы |
| Место материала | Mica — **базовый слой** окна и заголовка; Acrylic — временные поверхности (меню, поповеры) | S127 ✔ | «Стекло»: сайдбар/плеер/заголовок — Mica-слой окна, меню и поповеры — размытие (acrylic-подобное) |
| Читаемость стекла | Liquid Glass: вариант **regular** «для читаемости по умолчанию» — размывает и корректирует яркость фона; для плотного текста (алерты, сайдбары, поповеры) — именно он; из слоя контента стекло убирают; Reduce Transparency/Increase Contrast меняют вид. Критики: в ранних бетах контраст ~1,5:1 → Apple **повысила непрозрачность** панелей | S128 (Apple HIG Materials) ✔, S129 (infinum, Wikipedia) ○ | Стекло только на «хроме» (сайдбар, плеер, меню), **не на контенте**; плотность стекла — функция от измеренного контраста (7:1 худший случай), текст не светлеет — стекло плотнее |
| Тонировка цветом обложки | Apple Music (iOS 26.4): фон списка треков тонируется «под» обложку, не точно; Spotify: цвет верха страницы из обложки; у обоих — только область-шапка | S130 (9to5mac, bzamayo) ○; S131 (Spotify Community) ○ | Три зоны владельца: «Сейчас играет», шапки альбома/исполнителя, подложка плеера; сырой цвет — не в контролы |
| ChatGPT / Яндекс Музыка | У ChatGPT desktop — режим System/Light/Dark, **акцент из 8 цветов**, отдельная настройка «Контраст» (web и Windows) ✔; материалов нет | S132 (OpenAI Help, «Updating your visual experience») ✔ | Идея отдельной настройки «Контраст» ≈ наш высококонтрастный режим |
| Яндекс Музыка | Данных о материалах и тонировке не найдено | — | ◌ Ничего не утверждаем |

**Вывод:** четыре материала владельца ложатся на документированную практику (запасной сплошной цвет; стекло только на хроме; плотность по читаемости). Свечение «Живой свет» **не имеет документированного аналога** у вендоров (ближайшие — Apple Music/Spotify тонируют *шапку*, а не дрейфующее поле): это решение владельца, пометка в D-128.

## V-02. Доступность AAA (фича 1, п. 4)

| Правило | Источник |
|---|---|
| 1.4.6 «Контраст (повышенный)», AAA: текст ≥ 7:1, крупный ≥ 4,5:1 | WCAG 2.2 ✔ (S133; значения подтверждены общеизвестным текстом стандарта, веб-поиск страницу не вернул — сверить с Understanding 1.4.6) |
| 1.4.11 «Контраст нетекстовых элементов» (AA): границы контролов и значки ≥ 3:1 | WCAG 2.2 ✔ (S133) |
| 2.5.5 «Размер цели (повышенный)», AAA: ≥ 44×44 CSS-px, исключения — равнозначный контрол, строка текста, системный размер | W3C Understanding 2.5.5 ✔ (S134); 2.5.8 (AA) — 24×24 |
| Reduce Transparency / Increase Contrast на платформе меняют материал | Apple HIG (S128) ✔; Windows «Эффекты прозрачности» (S127) ✔ |

Решение: «невидимая» зона 44×44 вокруг визуально меньших контролов — приём из требования 2.5.5 (расширение области клика, а не рисунка).

## V-03. Селектор тем, авто-ночь, «Оформление» (фича 2)

**Референсы (6):** Telegram (Android/iOS/Desktop) ○ · ChatGPT desktop ✔ · macOS «Оформление» ○ · Windows 11 «Персонализация» ○ · Spotify ◌ · Apple Music (следует системе) ◌.

| Что | Как у референса | Источник | Берём |
|---|---|---|---|
| Режимы авто-ночи | Telegram: «Автоматически» (по датчику света, порог) и **«По расписанию»: по времени или по рассвету/закату** (закат требует геолокацию); тема для ночи выбирается отдельно, можно назначить свою | S135 (Android Police, Windows Central, mobigyaan, neowin) ○ | Режимы: Вручную / Как в Windows / По солнцу / По расписанию; пара тем день+ночь |
| macOS | «Оформление»: Светлое / Тёмное / **Авто** (закат→рассвет по умолчанию) | S136 (Zapier) ○ | «По солнцу» — тот же смысл |
| ChatGPT | Appearance: System / Light / Dark + акцент из 8 цветов — в одной панели настроек | S132 ✔ | Режим + цвет рядом, без «Сохранить» |
| Windows 11 | Личная настройка: выбор режима Light/Dark; **автоматического расписания в самой Windows нет** (его дают сторонние утилиты: Auto Dark Mode) | S137 (Mobilesyrup, Pureinfotech) ○ — 2021–24, перепроверить на сборке 26300 | Расписание/солнце — **наша** функция, «Как в Windows» читает системную тему (`prefers-color-scheme`) |
| Карточки тем с мини-превью | У Telegram — карточки тем с мини-чатом (формулировка владельца) | ◌ источник не найден; ТЗ владельца | Делаем по ТЗ владельца; в записях не пишем «как у Telegram» без скриншота |
| Круговая смена темы из точки клика | Приём «View Transitions API с `clip-path: circle()`» — веб-практика; у Telegram — по описанию владельца | ◌ не подтверждено поиском; технически — WebView2 (Chromium) поддерживает View Transitions (проверить на версии рантайма — спайк) | Делаем по ТЗ владельца; технику проверяем спайком T-спайк «круг» |
| Сезонные темы | Предложение карточкой, не уведомлением — решение владельца и D-82 (системных уведомлений нет) | D-50, D-82 | Как в ТЗ |

## V-04. «Рубин» (фича 3)

**Референсы (по ощущению, владельца):** скриншот iOS 26 Telegram с Liquid Glass (белый фон, серые пузыри, красный исходящий) · Apple Music macOS, светлая тема (красный акцент, выбранный пункт — серая плашка).

- Apple Music macOS: сайдбар — серая плашка выбранного пункта, акцентная иконка. Прямого источника нет; рядом найден только форум-пост про «серый с красной обводкой» у одного пункта (S138, MacRumors) ○ → ◌ **подтверждаем по скриншотам владельца**.
- Расчёты вместо «как у X»: опорные цвета владельца (#EA0012, #FEFFFF, #F0F1F4, #C3C3C4) проверены на контраст — см. D-130 и `DESIGN.md` §16.4. Главный вывод расчёта: белый на #EA0012 — 4,66:1 (не проходит текст 7:1), поэтому красный разделён на «яркий» (всё, что не текст: ≥ 3:1, 4,65:1 на белом) и «тёмный» (текст и заливки с текстом, 8,04:1 на белом).
- Apple HIG (S128): стеклу на светлом нужна кромка — подтверждает требование владельца про белое стекло на белом.

## V-05. Пожелание на экране волны (фича 4)

**Референсы (6):** приветствие Claude (формулировка владельца) ◌ · Apple Weather (иконки погоды, анимация) ◌ · Яндекс Погода ◌ · Google Now/Assistant «Доброе утро» ◌ · iOS Home Screen/Today ◌ · Spotify «Good morning» ◌.

Поиск не дал первоисточника ни по одному из приложений (только универсальные компоненты «приветствие по времени суток»: 4 периода — утро/день/вечер/ночь, S139 Framer ○). **Пробел зафиксирован честно:** приёмы (фраза по времени суток, иконка погоды) — общеизвестны, но «как у X» в записи не пишем. Что берём как **инженерное решение, не копию**: разбиение суток по солнцу (волна уже считает его, `14` §3, D-77), погода из того же кэша Open-Meteo (FR-CTX-002), словарь с грамматическими формами (морфология русского: род, число, падеж — своя таблица, без внешней библиотеки). Ограничения тона из ТЗ (без упрёков, без здоровья, без негатива о погоде) — решения владельца.
