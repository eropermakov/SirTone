Обозначения: ✅ утверждено владельцем · 🔧 решение проектировщика (меняется через ADR) · **M** обязательно в v1.0 · **S** желательно · **C** возможно позже · **Ст.** — этап (0–7, `09_ROADMAP.md`) · **Реф.** — основание в `01_*` (A — автомикс, B — визуализация, C — архитектура, F-xx — фишки).

## 0. Как читать

- Каждое требование имеет ID `FR-<ОБЛАСТЬ>-NNN`. Приёмка — кратко, подробно — в сценариях AT-01…AT-24 (§24) и в тест-планах `08`.
- Требования, помеченные ✅, — ваши; 🔧 — мои уточнения по референсам; ❓Q-n — вопрос к вам (`10` §5), до ответа действует предложенное. Расхождения и допущения — `10_DECISIONS.md`.
- Глоссарий: **вайб** — набор признаков трека (valence/arousal/…); **волна** — бесконечный поток по фильтрам; **профиль волны** — JSON-описание одной волны для общего движка (§26); **контекстное ведро** — сочетание «время суток × сезон × погода», в котором учатся «не сейчас» и контекстные предпочтения; **Неизвестные** — раздел для не опознанного с уверенностью; **деки** — два внутренних воспроизводящих канала движка.

## 1. Продукт и принципы

«Сиртон» — офлайн-плеер для уже скачанной музыки с автораспределением по библиотеке, «Моей волной» и визуализацией по настроению трека. «Офлайн-стриминг»: опыт как у Яндекс Музыки/Apple Music, но на локальной коллекции ✅.

| Принцип ✅ | Измеримый критерий (🔧) |
|---|---|
| Скорость | Реакция на нажатие **≤ 400 мс** (жёсткий потолок), цель p95 ≤ 100 мс; старт трека ≤ 150 мс |
| Красота | Анимации по всему интерфейсу, управляются пресетом производительности |
| Лёгкость | «Очень слабое» → почти голый плеер; idle RAM ≤ 250 МБ на 50 000 треках |
| Офлайн-first | Все функции, кроме онлайн-распознавания, погоды и популярности треков для «Для всех», работают без сети (без них — деградация с честной подписью) |
| Оригинальное качество | Файлы не перекодируются и не изменяются; индикатор «Bit-perfect/Resampled/DSP» |
| Минимум ошибок | Нет уверенности → «Неизвестные», а не неверная папка |
| Одна библиотека | Без профилей, синхронизации, бэкапов |
| Бесплатно | Только бесплатные/открытые сервисы; лицензии — `08` §3 |
