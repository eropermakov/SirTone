> Версия 1.0 · 2026-10-15 · основа: «Сиртон — ТЗ (черновик v0.1)» владельца + исследование референсов (`01_*`) + решения проектировщика.
> Студия: Серков Studio («Серков Team»). Платформа: Windows 10/11 x64. Стек: Tauri 2 (Rust) + React/TypeScript.

Обозначения: ✅ утверждено владельцем · 🔧 решение проектировщика (меняется через ADR) · **M** обязательно в v1.0 · **S** желательно · **C** возможно позже · **Ст.** — этап (0–7, `09_ROADMAP.md`) · **Реф.** — основание в `01_*` (A — автомикс, B — визуализация, C — архитектура, F-xx — фишки).

## 0. Как читать

- Каждое требование имеет ID `FR-<ОБЛАСТЬ>-NNN`. Приёмка — кратко, подробно — в сценариях AT-01…AT-12 (§14) и в тест-планах `08`.
- Требования, помеченные ✅, — ваши; 🔧 — мои уточнения по референсам. Расхождения и допущения — `10_DECISIONS.md`.
- Глоссарий: **вайб** — набор признаков трека (valence/arousal/…); **волна** — бесконечный поток по фильтрам; **Неизвестные** — раздел для не опознанного с уверенностью; **деки** — два внутренних воспроизводящих канала движка.

## 1. Продукт и принципы

«Сиртон» — офлайн-плеер для уже скачанной музыки с автораспределением по библиотеке, «Моей волной» и визуализацией по настроению трека. «Офлайн-стриминг»: опыт как у Яндекс Музыки/Apple Music, но на локальной коллекции ✅.

| Принцип ✅ | Измеримый критерий (🔧) |
|---|---|
| Скорость | Реакция на нажатие **≤ 400 мс** (жёсткий потолок), цель p95 ≤ 100 мс; старт трека ≤ 150 мс |
| Красота | Анимации по всему интерфейсу, управляются пресетом производительности |
| Лёгкость | «Очень слабое» → почти голый плеер; idle RAM ≤ 250 МБ на 50 000 треках |
| Офлайн-first | Все функции, кроме онлайн-распознавания и погоды, работают без сети |
| Оригинальное качество | Файлы не перекодируются и не изменяются; индикатор «Bit-perfect/Resampled/DSP» |
| Минимум ошибок | Нет уверенности → «Неизвестные», а не неверная папка |
| Одна библиотека | Без профилей, синхронизации, бэкапов |
| Бесплатно | Только бесплатные/открытые сервисы; лицензии — `08` §3 |

## 24. Приёмочные сценарии (AT-01…AT-12)

Каждый сценарий — автоматизируемый, где возможно (E2E + скрипты), иначе чек-лист на реальном железе (Ryzen 7 5800H, Radeon iGPU, 15 ГБ — машина владельца; «слабое» — эмуляция: 2 ядра, без GPU-ускорения).

| AT | Сценарий (из ТЗ §21) | Критерии успеха |
|---|---|---|
| AT-01 | **Первый запуск**: пустое приложение → первичная настройка → обучалка → перетаскивание папки с флешки → автораспределение → флешка вынута | Мастер ≤ 5 шагов; 500 треков копируются и становятся играбельными по мере копирования; после «Можно извлекать» все файлы в хранилище, воспроизведение продолжается; структура `Артист/Альбом/Трек` видна в проводнике |
| AT-02 | **Ночной вайб**: «Моя волна» на весь экран, грустный трек → энергичный | Визуализация меняет палитру/движение плавно ≤ 3 с; переход автомикса: ошибка фазы битов ≤ 20 мс (при L3), уровень на стыке ±1 dB; нет щелчков |
| AT-03 | **Работа с фоном**: хоткеи/виджет, видео в браузере, закрытие окна | Хоткей реагирует ≤ 150 мс; приглушение начинается ≤ 700+150 мс после старта чужого звука, возврат ≤ 2,2 с после окончания; закрытие окна — музыка играет из трея |
| AT-04 | **Компьютер без интернета (портативно)**: часть треков без тегов → «Неизвестные» → сеть появилась | Без сети импорт не блокируется; после появления сети ≥ 90 % распознаваемых треков доопределяются и переезжают в течение запросного бюджета; журнал перемещений согласован |
| AT-05 | **Дубли**: пачка с уже существующими под другими названиями | Отчёт показывает 3 класса; «заменить» переносит статистику/плейлисты; ложные срабатывания на золотом наборе < 1 % |
| AT-06 | **Ошибка распределения**: DnD трека к другому исполнителю; два написания исполнителя → слияние | Перемещение файла и обновление БД ≤ 1 с; слияние объединяет треки/альбомы, алиас запоминается |
| AT-07 | **Гибридный плейлист**: 3 трека → похожие под разделителем → «+» → стоп | Порядок по близости; «+» добавляет в плейлист; когда похожих нет — остановка; «−» исключает |
| AT-08 | **Настройка волны**: «энергичное + без слов + забытые + тренировка»; дождь и вечер → контекст предлагает, пользователь переопределяет | Все выбранные фильтры соблюдены (при достаточности треков) или показано «расширил подбор»; переопределение мгновенно |
| AT-09 | **Отдать другу**: экспорт исполнителя | Файлы побайтово идентичны исходным копиям в хранилище; структура сохранена |
| AT-10 | **Слабый ноутбук**: «слабое»/«определить» → перегрев → автоснижение | Тяжёлые эффекты выключены; после просадки уровень понижен и остаётся таковым до ручного возврата |
| AT-11 | **Bluetooth-колонка**: меню → подключить → играть → отключить | Подключение ≤ 10 с на устройстве владельца; вывод идёт на колонку; отключение без захода в настройки Windows (иначе явный fallback) |
| AT-12 | **Длинный файл**: 3-часовой микс | Помечен «возможно, не трек»; «нормальный» + назначение исполнителя/плейлиста работает |
