> Версия 3.0 · 2026-11-05. Решения приняты (ждут подтверждения владельца вместе с D-131…D-142), приложение не пишем. Потом оно собирается на том же ядре, токенах и экранах (`README.md`).

## 1. Решения

| Что | Решение |
|---|---|
| Язык и интерфейс | Kotlin, Jetpack Compose; цвета и шрифт Сиртона вместо Material You |
| Ядро | Те же Rust-крейты, UniFFI, сборка через `cargo-ndk` для arm64 |
| Минимальная версия | Android 10, уточняем перед началом разработки |
| Звук | Rust выводит в AAudio |
| Система | Media3 `MediaSessionService`: уведомление, экран блокировки, наушники |
| Виджет | Glance, те же размеры и кнопки |
| Импорт | Системный выбор файлов и папок, «Поделиться» через intent |
| Анализ | WorkManager на зарядке |
| Подпись | Свой ключ проекта, 7-дневного срока нет; ключ — в секретах GitHub и офлайн-копия у владельца |
| Установка и обновление | Хаб по кабелю, ADB (`adb_client`, MIT, чистый Rust, без отдельного сервера ADB) |
| Идентификатор | `studio.serkov.sirtone.mobile` (Q-31) |

## 2. Чем отличается от iPhone

| iPhone | Android |
|---|---|
| Системный таб-бар | Нижняя панель навигации в стиле Сиртона |
| Динамический остров | Медиа-уведомление и шторка |
| Жест назад от края | Системный жест и кнопка «Назад» |
| Пункт управления | Быстрые настройки и медиа-панель |
| Продление подписи раз в 7 дней | Не нужно |

## 3. Установщик Android в хабе

1. Хаб замечает телефон и показывает инструкцию под его производителя.
2. Человек открывает «О телефоне» и 7 раз нажимает «Номер сборки».
3. Включает «Отладку по USB» и нажимает «Разрешить» на телефоне.
4. При необходимости хаб ставит драйвер WinUSB — для этого нужны права администратора (**Q-25**: сейчас `08` §4 п. 7 запрещает админ-права для любой функции; **Q-27**: libwdi — LGPL-3.0).
5. Тот же выбор: «Перенести всё», «Выбрать», «Только приложение».
6. Установка через `adb_client`.

## 4. Проверка разработчиков Google

С 30 сентября 2026 Google требует регистрацию разработчика на сертифицированных устройствах в Бразилии, Индонезии, Сингапуре и Таиланде; в 2027 правило станет мировым (источник — блог Android Developers, `01d`). Установка через ADB от этого освобождена; ручная установка незарегистрированного APK потребует «продвинутый путь» с 24-часовым ожиданием (Android Authority). Поэтому основной путь — кабель через хаб; решение о регистрации — до мирового запуска (OWN-21).
