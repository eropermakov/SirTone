# Полный порт на телефон и обстановка (принято владельцем 2026-11-08: D-148…D-150)

Запрос владельца 2026-11-08 (после первого дня с медиатекой на iPhone): на телефоне должно быть всё, что есть на ПК, — настройки, эквалайзер, визуализация, — адаптированное к телефону, и Сиртон сам понимает обстановку: иду, еду, долго еду, на работе, дома, погода, время суток.

Сейчас в `mobile/README.md` §3 эквалайзер, автомикс, фокус, контекст — волна 2, визуализация — волна 3, а контекст — «занятие вручную». Предложение меняет и то и другое, поэтому сначала подтверждение (`12` §1.1), потом правка ТЗ (`02`, `10`, `13`, CHANGELOG) и код.

## 1. Что есть на ПК и чего нет на телефоне

| Раздел ПК | На телефоне сейчас | Предложение |
|---|---|---|
| Звук: эквалайзер 10 полос и пресеты (`settingsEq`) | нет | **Порт.** EQ уже в ядре (`sirtone-audio`, собирается под телефон); экран «Звук» с полосами и пресетами |
| Автомикс «Мягко / Умно / Как диджей» (`settingsMix`) | нет | **Порт** «Мягко» и «Умно»; «Как диджей» — после замера нагрузки на iPhone |
| Нормализация, gapless | в ядре | Переключатели в «Звук» |
| Звуки интерфейса (`settingsSfx`), живые эффекты (`settingsFx`) | нет | Порт с тактильным откликом вместо части звуков |
| Визуализация (`viz`, `settingsViz`) | нет | **Порт.** Полноэкранная из «Сейчас играет», те же пресеты; движок — после спайка (§4) |
| Волна (`settingsWave`): знакомое ↔ неожиданное, влияния, «Никогда» (`settingsNever`) | шторка без «силы влияний», ползунка и «Никогда» | Порт целиком в «Настройки → Волна» и шторку |
| Профили: Сезонная, Событие, Для всех (`events`, `settingsEvents`) | в ядре (`start_profile`), на экране только «Засыпательная» | Порт: «Мои волны» на вкладке «Волна», карточки событий |
| Фокус 25/5 (`focus`, `settingsFocus`) | нет | Порт с кольцом-таймером и Live Activity позже |
| Сон (`settingsSleep`) | есть (таймер) | Добавить настройки: длительность затухания, «до конца трека» |
| Место и погода (`settingsPlace`) | нет | **Обстановка** (§2) |
| Умные плейлисты (`smart`), смысловой поиск | нет | Порт |
| Теги, дубли, слияние исполнителей, раскладка (`tags`, `dups`, `artistMerge`, `organize`) | нет | Порт по одному экрану; правка тегов — через журнал, как на ПК |
| Хранилище (`settingsStorage`), экономные копии | есть | — |
| Темы, цвета, сезонные темы | темы и 17 цветов | Сезонные темы — порт |
| Производительность, пресеты (`settingsPerf`) | «Только музыка» | Пресеты «Лёгкий / Обычный / Максимум» как на ПК |
| Язык (`settingsLanguage`) | только русский | Порт (ru, en) |
| Сеть, офлайн-тумблер (`settingsNet`) | нет | Порт: один тумблер «Без интернета» |
| Виджет (`widget`) | нет | WidgetKit (было F11) |
| **Не переносим** | | Горячие клавиши, автозапуск, трей, мини-бар, Bluetooth-меню, приглушение на звонок, обновления — на iPhone это делает система или хаб |

## 2. Обстановка на телефоне (новое F18 вместо «занятие вручную»)

Как у Endel, Google Awareness, Samsung Modes, Spotify «В машине» (`01d` §F). Всё считается на телефоне, наружу уходят только округлённые координаты в Open-Meteo (хост уже разрешён, `08` §4).

| Сигнал | Откуда | Что значит для волны |
|---|---|---|
| Время суток, сезон, праздники | часы и календарь ядра (уже есть) | как на ПК |
| Погода за окном | Open-Meteo раз в 30–60 мин; место — город, как на ПК, или грубое место телефона (координаты до 0,1° ≈ 10 км) | как на ПК |
| Иду / бегу / велосипед | Core Motion, уверенность ≥ средней, ≥ 2 мин подряд; шаг в минуту — темп (как Endel) | иду → «В пути», бегу/велосипед → «Тренировка», темп волны ближе к шагу |
| Еду | Core Motion «в машине» + подтверждение: выход звука CarPlay или Bluetooth, отмеченный «Это машина» (Spotify так не умеет) | «В пути» |
| Долго еду | «Еду» больше 20 минут | «В пути» и меньше резких переходов, длиннее треки |
| Дома / на работе | место запоминается, пока приложение открыто или играет музыка; ночные часы → «Дом», будни днём → «Работа»; человек может поправить («Я дома», «Я на работе») | дома вечером → «Отдых», на работе → «Работа», ночью дома → подсказка «Засыпательная волна» |
| Наушники / динамик | выход звука | в динамике тише и мягче переходы |
| Энергосбережение | iOS | как сейчас «Только музыка» |

**Правила.**
- Обстановка подсказывает, а не командует: веса волны сдвигаются, как от «Занятия по активному приложению» на ПК; карточка «Похоже, вы в дороге — волна под дорогу» с отменой; ручная «Настроить волну» всегда главнее.
- «Почему этот трек» называет причину: «Вы в пути», «Дождь за окном».
- Разрешения — в момент пользы: «Движение и фитнес» — при первом включении обстановки, «Геопозиция при использовании» — при включении погоды или мест. «Всегда» не просим.
- Каждый сигнал выключается в «Настройки → Волна → Обстановка». История мест и движения хранится только на телефоне и стирается одной кнопкой; при переносе на ПК не уходит.
- Бесплатный Apple ID это позволяет: Core Motion, Core Location и выход звука платных разрешений не требуют. Пульс («Здоровье») не берём.

## 3. Порядок (предложение)

1. **Сейчас:** экран «Настройки» по разделам ПК — «Звук» (эквалайзер, нормализация, автомикс «Мягко»/«Умно»), «Волна» (всё из шторки, ползунок, влияния, «Никогда»), «Обстановка»; обстановка v1: время суток, погода, движение, машина по выходу звука; профили «Сезонная», «Событие», «Для всех».
2. **Следом:** визуализация (после спайка §4), «Дом» и «Работа», «Фокус», умные плейлисты и смысловой поиск, пресеты производительности, язык.
3. **Затем:** теги, дубли, слияние, раскладка; виджет и быстрые действия; самопродление; сезонные темы, MilkDrop и видео-фон.

Каждый шаг — сборка на iPhone и проверка владельцем, П3 перезапускается при каждой установке (принято владельцем 2026-11-08).
