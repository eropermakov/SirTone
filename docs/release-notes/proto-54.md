# Сиртон 0.2.8 — beta candidate 54

- Исправлен перенос медиатеки на iPhone: проверка свободного места больше не требует лишнюю полную копию пакета.
- «Экономно» и «Максимально» перекодируют до четырёх треков одновременно, сохраняя отзывчивость ПК.
- Передача на телефон показывает маршрут реальных этапов: подготовка, перекодирование и отправка; при уменьшении движения маршрут остаётся статичным.
- Добавлены диагностика, добровольная обратная связь и безопасная подготовка технического отчёта для бета-тестирования.

Это beta candidate, а не стабильный публичный выпуск: Windows Authenticode-подпись и production Feedback API ещё не настроены, а iPhone требует отдельной приёмки на устройстве.
