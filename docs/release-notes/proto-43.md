**Новый облик Сиртона — монохром и один красный акцент.**

- **Две темы — Тёмная и Светлая** (по умолчанию как в системе), плюс повышенная контрастность по системной настройке. Акцент по умолчанию — `#650A12`; выбор из 17 цветов и «Авто» из обложки остаётся. Прежние темы (лайм, Fabric, «Оранжевая», «Чёрно-белая») убраны: открываются как «Авто».
- **Меню как у Apple:** шапка с кругом акцента, строки по 52 px с нейтральной капсулой у выбранной, поиск первой строкой, сверху панель «назад / вперёд» с названием, большая надпись раздела (кроме «Моей волны»).
- **Стекло:** в настройках три уровня — Прозрачное, Среднее, Матовое; панели над визуализацией размывают фон. Если текст читается плохо, плотность поднимается сама; при слабой машине, высоком контрасте или «Уменьшить прозрачность» панели плотные.
- Радиусы, кнопки, переключатели и движение приведены к новому дизайну; «Уменьшить движение» оставляет только прозрачность.
- Сезонные и событийные темы больше не меняют цвет интерфейса — только палитру визуализации и карточки событий.
- iPhone: цвета и контрастные палитры из того же дизайна (проверка на телефоне — отдельным прогоном).
- Всё из прототипа 42 — без изменений.
