**Исправления по прототипу 32.**

- **Меню Bluetooth** открывается вверх и больше не уходит за край экрана.
- **Исполнители** — на карточке круглая обложка их главного альбома вместо букв.
- **Обложки из интернета** докачиваются, даже если в первый раз не было сети (ноутбук только проснулся): следующая попытка — через полчаса, а не после перезапуска.
- **Громкость колесиком мыши**: наведите на регулятор громкости внизу и крутите — 5 % за щелчок.
- **MilkDrop больше не обрезается**: на уровне производительности «Мощное» картинка занимала только часть экрана — теперь на весь.
