# Сиртон 0.2.6 — прототип 52

- Локальные пространства: на одном ПК можно создать отдельные места для разных людей. Музыка, плейлисты, настройки и рекомендации не смешиваются; переключение безопасно перезапускает приложение.
- При добавлении папки или перетаскивании музыки теперь выбирается качество: исходное, Opus 128 кбит/с или Opus 64 кбит/с. Оригинальный файл не изменяется.
- На iPhone экран «Сейчас играет» в горизонтальной ориентации перестраивается: обложка слева, управление и информация справа.
- Мелкие анимации меню и диалогов учитывают системное снижение движения.
