# Сиртон 0.2.6 — прототип 52

- Локальные пространства: на одном ПК можно создать отдельные места для разных людей. Музыка, плейлисты, настройки и рекомендации не смешиваются; переключение безопасно перезапускает приложение.

- Код горизонтального экрана «Сейчас играет» для iPhone подготовлен в исходниках; он будет включён отдельным мобильным выпуском, а не Windows-установщиком.
