**Версия 0.2.1 — фото исполнителей и обложки треков из интернета.**

- «Исполнители»: у карточек без обложки альбома появляются фото исполнителей (Deezer, при почти точном совпадении имени).
- Треки без альбома или с альбомом без обложки получают обложку по поиску трека (Deezer: исполнитель + название); если не нашлась — фото исполнителя, иначе прежняя заглушка. Вшитые и выбранные вами обложки не заменяются, файлы и теги не меняются.
- Запуск: «Настройки → Данные сервиса → Найти обложки» и после импорта, только при выключенном офлайне.
- Из 0.2.0 без изменений: «Мой поток», масштаб, акценты, iPhone.

Почему у части треков обложки нет: в файле нет вшитой картинки, рядом нет файла-обложки, а по альбому нет уверенного совпадения (или у трека нет альбома).

Не проверено: поиск Deezer по исполнителям и трекам не запускался на живом сервисе; фото исполнителя, встав как обложка трека, не заменится позже найденной настоящей обложкой; перенос этих обложек на телефон не сделан (отдельная задача мобильной линии).
