**Все треки.**

- **«Все треки»** в «Коллекции»: вся музыка одним списком. Сортировка — по названию, исполнителю, альбому, длительности или дате добавления; повторный выбор переворачивает порядок. «Слушать» играет весь список, двойной щелчок — с выбранного трека.
- Всё из прототипа 35 («Титры», автомикс «как у диджея», тег языка, полоски у играющего трека, справка по F1) — без изменений.
