**Плейлисты.**

- «Новый плейлист» вверху боковой панели: сразу можно ввести название; плейлисты — в группе «Плейлисты».
- Меню трека → «Добавить в плейлист ›»: в любой плейлист или в новый. Если трек там уже есть — спросим, добавить ли ещё раз.
- Страница плейлиста: обложка-мозаика, «Слушать», переименование щелчком по названию, удаление плейлиста (треки остаются в медиатеке).
- «Убрать из плейлиста» (или клавиша Delete) убирает только строку — трек и файл на месте.
