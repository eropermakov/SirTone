**Сиртон на новый iPhone — прямо из ПК-Сиртона.**

- **«Телефоны» → «Установить Сиртон» теперь работает на любом iPhone.** ПК-Сиртон сам скачивает приложение для iPhone, проверяет его подпись и ставит на телефон. Нужен интернет, кабель и Apple ID человека, чей это телефон. Пароль и код вводит он сам.
- После первой установки телефон сам попросит включить «Режим разработчика» и доверять разработчику, мастер подскажет шаги.
- Бесплатный Apple ID даёт приложению 7 дней. Если Сиртон поставлен из этого ПК, срок продлевается сам, пока ПК-Сиртон открыт и телефон рядом.
- Всё из прототипа 41 — без изменений.
