**Карточка трека, удаление и «Неизвестные».**

- «Неизвестные»: фильтры по причинам и панель «Назначить» — укажи название и исполнителя, файл сам переедет в папку исполнителя.
- Карточка трека (меню трека → «Ещё» → «Изменить данные»): формат, частота, битрейт, размер, путь к файлу; правка данных переносит файл на правильное место.
- Удаление трека всегда спрашивает: «удалить файл с диска (в Корзину)» или «только убрать из приложения». Удаление исполнителя показывает, сколько треков и мегабайт уйдёт.
- Меню трека: «К альбому / исполнителю ›», «Показать в проводнике».
