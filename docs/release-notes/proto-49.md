**Версия 0.2.3 — обложки у синглов.**

- У треков без альбома (синглы, папка «Singles») теперь видна обложка, вшитая в сам файл. Раньше Сиртон сохранял вшитую картинку только как обложку альбома, и у синглов оставалась заглушка; поиск в интернете такие треки пропускал, потому что картинка в файле есть (D-174).
- Уже добавленная музыка подхватит обложки сама при первом запуске новой версии, ничего нажимать не нужно. Файлы не меняются.
- Исполнитель, у которого есть только синглы, получает обложку своего последнего сингла.
- Обложки синглов уходят и на телефон при «Перенести на телефон» (нужен Сиртон для iPhone 0.2.3).

Не проверено: дозаполнение обложек проверено тестами на ПК, на настоящей медиатеке — после установки.
