**Цвет «Авто» и итог второго этапа.**

- Настройки → Цвет → «Авто» (первый кружок): цвет приложения подбирается по обложке играющего трека из готовых наборов.
- Окна-вопросы теперь удерживают фокус клавиатуры внутри, как положено.
- Этап 2 («Интерфейс») завершён: плейлисты, поиск, жанры, перетаскивание, «Моя волна»-плеер, первая настройка. Дальше — умная волна.
