# Ручная приёмка беты

Статус всех пунктов ниже: **не пройдено**. Этот лист не заменяет автоматические проверки и не позволяет отмечать физическое устройство как проверенное без владельца.

## Windows — второй ПК

- [ ] Установить Windows Beta на чистый профиль; подтвердить WebView2 и запуск без прав администратора.
- [ ] Пройти первый запуск: добавить музыку, запустить трек, открыть «Мой поток», найти настройки звука и «Помощь и обратная связь».
- [ ] Импортировать небольшую и большую медиатеку; прервать импорт и перезапустить приложение; убедиться, что музыка и БД не потеряны.
- [ ] Проверить встроенные/USB/Bluetooth-устройства, отключение выхода и последующее восстановление воспроизведения.
- [ ] Выполнить 24-часовое воспроизведение на отдельном ПК; отметить недогрузы, выход из сна и сохранность очереди.
- [ ] Проверить portable-режим отдельно: нет неожиданной записи в профиль, обновление честно сообщает ограничения.
- [ ] Проверить обновление с предыдущей подписанной беты: база, настройки, плейлисты и локальные пространства сохранены; при ошибке обновления прежняя версия запускается.
- [ ] В «Помощь и обратная связь» создать ZIP, убедиться в составе без музыки/путей/токенов; отправить тестовое обращение после развёртывания HTTPS API и получить письмо.
- [ ] Удалить приложение: пользовательские данные остаются или удаляются только в явно выбранном сценарии; восстановить запуск из сохранённых данных.

## iPhone №1

- [ ] Установить сборку, открыть, пройти первый запуск и перенести музыку с ПК.
- [ ] Проверить фоновое воспроизведение, экран блокировки, Bluetooth, «Мой поток», автомикс и визуализации.
- [ ] Выполнить M9.1–M9.13 из `docs/mobile/checks.md` на реальном устройстве.
- [ ] Создать и отправить диагностический отчёт; проверить, что в архиве нет медиа, путей, истории или токенов.
- [ ] При настроенной Почте проверить системный fallback; без Почты — экспорт/Share Sheet.
- [ ] Наблюдать батарею и нагрев при обычном использовании и длительном воспроизведении.

## iPhone №2

- [ ] Повторить чистую установку на другом устройстве и проверить независимую библиотеку.
- [ ] Проверить другую версию iOS/окружение, импорт, воспроизведение и перенос.
- [ ] Отправить отдельный диагностический отчёт; Installation ID должен отличаться от iPhone №1.
- [ ] Проверить обновление и повторную установку: Installation ID сохраняется при обновлении и меняется лишь после явного сброса данных диагностики.

## Семидневная подпись iPhone

- [ ] За два дня до окончания открыть хаб Windows и проверить понятное предупреждение/продление.
- [ ] На седьмой день подтвердить, что повторная подпись не удаляет музыку, библиотеку или настройки.
- [ ] Если автоматическое продление недоступно, проверить ручной понятный сценарий через раздел «Телефоны».
