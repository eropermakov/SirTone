# 01f. Исследование: качество при локальном импорте

> Дополнение к 3.14 · 2026-11-17. Цель — дать человеку выбор между размером и качеством **в момент добавления музыки**, не уничтожая исходник и не смешивая выборы разных пакетов.

## Референсы и выводы

| Продукт | Наблюдаемый паттерн | Что берём в «Сиртон» |
|---|---|---|
| Apple Music / iTunes для Windows | В Import Settings выбираются кодек и пресет; качество связано с размером. При преобразовании создаётся новая версия рядом с оригиналом, а оригинал остаётся. [Apple: import settings](https://support.apple.com/en-gb/guide/itunes/itns2965/windows), [Apple: convert and keep original](https://support.apple.com/en-mn/108961) | Три понятных выбора без технического меню; оригинал остаётся первичным и не заменяется. |
| Apple Music для Windows | Для загрузок предлагает градации High Quality / Lossless / Hi-Res Lossless, привязывая их к месту и устройству. [Apple: playback/download quality](https://support.apple.com/en-bh/guide/music-windows/musdf855a1b/windows) | Выбор делается локально для одной операции, а не становится неявным правилом для всей коллекции. |
| MusicBee | Конвертер использует профили качества; сообщество отдельно предупреждает не перекодировать уже сжатый MP3 без причины. [MusicBee converter profiles](https://getmusicbee.com/forum/index.php?topic=29092.0), [предупреждение о повторном сжатии](https://getmusicbee.com/forum/index.php?topic=43694.0) | Уже достаточно компактные Opus и низкобитрейтные файлы не перекодируются повторно. |

## Решение для SirTone

- Перед каждым добавлением файлов или папки, включая drag-and-drop, показывается один выбор: **Оригинал**, **Экономия — Opus 128 кбит/с**, **Максимальная экономия — Opus 64 кбит/с**. По умолчанию — «Оригинал».
- Сначала библиотека безопасно копирует и индексирует оригинал; после этого, только при выбранной экономии, создаёт дополнительную Opus-копию с тегами и обложкой. Воспроизведение на ПК продолжает читать оригинал.
- Выбор хранится в очереди именно с данным пакетом, поэтому параллельные добавления и разные локальные пространства не меняют качество друг друга. Повторно сжатые/уже достаточно компактные файлы пропускаются.
- Отдельная копия расходует место наряду с оригиналом. Удаление оригинала — отдельное явное действие для будущего интерфейса, не часть импорта.
