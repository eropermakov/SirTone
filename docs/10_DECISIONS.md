## 2. Ответы на открытые вопросы исходного ТЗ (§23)

| № | Вопрос | Решение (🔧 по референсам; меняется ADR) | Статус |
|---|---|---|---|
| 1 | Название раздела «Моя волна» | Временно «Моя волна» (ключ `nav.wave`); **риск совпадения с названием функции Яндекс Музыки**; кандидаты «Вайб», «Поток», «Волна» | **владелец** (OWN-09) |
| 2 | Один/несколько режимов визуализации | Все три как переключаемые; доступ по пресету (Волны ≥ 1, MilkDrop ≥ 3, Видео ≥ 4) | принято |
| 3 | Как определять «занятие» | **Ручной выбор** по умолчанию; авто по активному приложению — **opt-in**, по имени `.exe` без заголовков окон, локально | принято |
| 4 | Приоритет «теги vs имя файла» | Взвешенное расстояние и таблица решений (`05` §4.5): согласуются → ок; конфликт офлайн → «Неизвестные» с двумя кандидатами; онлайн → побеждает подтверждённый кандидат | принято |
| 5 | Геолокация для погоды | Ручной город (геокодер Open-Meteo) → по IP (опция) → без сети: последнее известное / только время суток (расчёт по солнцу локально) | принято |
| 6 | Счётчик прослушиваний | Да, невидимый, агрегат; правило Last.fm; без журнала событий и раздела истории | принято |
| 7 | Шрифты и дизайн | **Предоставляет владелец** (D-1…D-9); до этого нейтральный каркас и системный шрифт | **владелец** (OWN-07) |
| 8 | Где хранилище | Установленная: по умолчанию `%USERPROFILE%\Music\SirTone` (выбор на первом запуске), служебные данные `%LOCALAPPDATA%\SirTone`, БД рядом с хранилищем (`.sirtone\library.db`); портативная: рядом с exe или любая папка на том же носителе; **пути относительные** ⇒ перенос = копирование папки | принято |
| 9 | Файлы, добавленные через проводник | Принимаем **на месте** + предлагаем навести порядок (по умолчанию не двигать молча); настройка `organize_external` | принято |
| 10 | Виджет панели задач | Превью-кнопки + прогресс/overlay + Jump List + SMTC (+ опциональный мини-бар) | принято, мини-бар — спайк |
