# SirTone («Сиртон») — полный обзор проекта

> Сводка для обсуждения «что делать дальше». Состояние на **2026-10-26**. Источники — `docs/00…14`, `docs/reports/stage-7.md`, `13_BACKLOG.md`. Нормативные детали — в самих документах; здесь — общая картина.

## 1. Что это

**Сиртон** — локальный музыкальный плеер для Windows 10/11 от **Sir.kov Studio**. Идея: «офлайн-стриминг» — опыт как у Яндекс Музыки / Apple Music, но на своей скачанной коллекции.

Пользователь ставит приложение, перетаскивает музыку в окно — и дальше всё происходит само:
- файлы копируются в хранилище и раскладываются по папкам `Исполнитель / Альбом / Трек`;
- треки распознаются (теги, имя файла, папка, анализ звука, при наличии сети — MusicBrainz / AcoustID / Cover Art Archive);
- каждый трек анализируется на устройстве: громкость, темп, тональность, жанр, настроение, наличие вокала, «вайб»;
- работает «Моя волна» — бесконечная умная подборка из своей медиатеки, которая учится на прослушиваниях;
- фоном идёт визуализация под настроение трека.

**Главное с версии спецификации 2.0 (D-84): офлайн.** Без интернета приложение полезно целиком, модели анализа входят в установщик. Сеть — только дополнение (уточнение распознавания, обложки, погода, популярность, обновления). Никаких аккаунтов и ключей у пользователя.

- Идентификатор: `studio.serkov.sirtone` (менять нельзя).
- Репозиторий: GitHub `eropermakov/SirTone` (публичный — на нём держится канал обновлений, D-76).
- Текущая версия: **v0.1.34 (прототип 34)**, выпущен 2026-10-21.
- Объём кода: ~67 тыс. строк (Rust + TS/TSX).

## 2. Принципы владельца (законы проекта)

1. **Не изобретать — копировать.** Для каждой фишки сначала смотрим, как её делают 6+ популярных приложений (`docs/01*`), потом адаптируем.
2. **Спецификация — закон.** `02_TZ.md` (требования `FR-*`), отклонения — только через запись в `10_DECISIONS.md`.
3. **Визуал — `DESIGN.md`** (дизайн владельца, система Sir.kov Fabric): шрифт Geologica, правило 60–30–10, токены; UX-законы (Фиттс, Хик, Доэрти…) обязательны: отклик ≤ 100 мс на прямые действия, оптимистичный UI, скелетоны, ошибки — тостом.
4. **Скорость и лёгкость.** Реакция ≤ 400 мс (цель p95 ≤ 100), всё тяжёлое отключаемо пресетами производительности.
5. **Данные пользователя неприкосновенны.** Аудио не перекодируется, файловые операции — через журнал, удаление — только в Корзину, нет уверенности → «Неизвестные». Журнал прослушиваний и модели вкуса — только локально, телеметрии нет.

Процесс доработок: **правка спецификации → подтверждение владельца → код**. Коммит после каждой задачи, этапы в ветках `stage/N-…`, слияние в `main` после приёмки.

## 4. Фишки (что умеет приложение)

### 4.1. Воспроизведение и звук
- Форматы: MP3, FLAC, WAV, AAC/M4A, ALAC, OGG Vorbis, Opus, AIFF, WMA (+ CAF, MKA/WebM).
- **Оригинальное качество:** без перекодирования, индикатор тракта «Bit-perfect / Ресемплинг / DSP»; опция эксклюзивного WASAPI.
- **Gapless** (LAME/Xing, iTunSMPB, `elst`), предоткрытие следующего трека.
- **Умный автомикс** — «лестница» L0–L3: бесшовно → срезка тишины → перекрытие по огибающей громкости → beatmatch. Режимы Мягко / Умно / Как диджей; альбомы по порядку не микшируются. (Как у Apple, VirtualDJ, MPD MixRamp, Plexamp, Mixxx, djay.)
- **Нормализация** −19 / −14 / −11 LUFS, по альбому; ReplayGain/R128 или своё измерение.
- **Эквалайзер** 10 полос + preamp + ~18 пресетов.
- **Приглушение** при чужом звуке (по сессиям Core Audio), «Пауза во время звонка».
- Громкость — только своя, кубическая шкала; таймлайн с waveform.
- Выбор устройства вывода, «как в Windows», пауза при потере устройства.

### 4.2. Медиатека
- Импорт перетаскиванием: копирование, источник не трогается, «можно извлекать флешку»; отчёт «добавлено / Неизвестные / дубли / пропущено».
- **Распознавание** с тремя зонами уверенности (как beets/Picard): уверен → на место; средне → подсказка; иначе → «Неизвестные». Исправление кодировок тегов (cp1251 и др.), консенсус по папке.
- **Дубли по содержимому** (отпечаток): точная копия / тот же звук / другая версия; «заменить» переносит статистику.
- Исполнители и фиты (трек у каждого), слияние «Би-2 / Би 2», алиасы.
- Слежение за папкой, поиск переехавших файлов, офлайн-корень (вынутая флешка).
- Плейлисты: ручные, **умные** (схема Navidrome `.nsp`), **продолжение** похожими из своей медиатеки (как Roon Radio), «+ / −» на рекомендованных.
- **Поиск:** опечатки, раскладка (ghbdtn → привет), транслит, ё/е, русский стеммер, **смысловой поиск** («что-то грустное и медленное») — офлайн.
- Экспорт медиатеки или выборки обычными файлами; раздел «Хранилище».

### 4.3. Анализ на устройстве
- Громкость (EBU R128), пики, BPM и тональность, тембр/спектр.
- Встроенная ONNX-модель **EfficientAT mn10_as** (MIT) → жанр, настроение, вокал; вектор «вайба» (valence–arousal и др.).
- Фоновая работа: below-normal + EcoQoS, пауза при игре и батарее.

### 4.4. «Моя волна» — движок рекомендаций
- Один движок для всех волн: **контекст → кандидаты → скоринг → секвенсор → очередь**; каждая волна — JSON-профиль.
- Обучение: бета-модель по треку (полураспад ~90 дней) + онлайн-логистическая регрессия по признакам + исследование по Томпсону. Пересборка очереди на 50 000 треков — ~3 мс.
- Сигналы: лайк, «не сейчас» (минус только в текущем контексте), «никогда в волне»; короткая память сессии.
- **«Почему этот трек»** — объяснение из компонентов скоринга.
- **«Настроить волну»** — плитки по блокам (настроение, характер, язык, частота, занятие, обстановка, сезон, события, режим, сила влияний, диапазоны энергии/темпа).
- Ползунок **«Знакомое ↔ Неожиданное»**.
- Чипы «Состав волны» (что влияет сейчас — нажатием выключается), «Мои волны» (сохранённые настройки), «Волна по треку / исполнителю / альбому».
- Режимы-профили: **Моя волна, Сезонная, Событие, Сон, Фокус, Для всех**.
  - **Сезонная:** метеосезон, полушарие, смесь сезонов у границ, поправка погодой.
  - **События:** офлайн-календарь (Новый год, 8 марта, Масленица и Пасха алгоритмом, Хэллоуин, погодные и астрономические микро-события…), карточки-предложения без системных уведомлений.
  - **Сон:** таймер, кривая энергии вниз, затухание по перцептивной кривой, «+15 мин», после — ничего / выключить экран / сон ПК (только явной настройкой).
  - **Фокус:** циклы 25/5 (и др.), кольцо-таймер, ровная энергия, предпочтительно без слов.
  - **Для всех:** нейтральная подборка для компании (популярность из ListenBrainz, без грустного/агрессивного; личный вкус почти не влияет).
- Контекст: время суток по солнцу, погода Open-Meteo (без ключа), занятие (вручную; по активному приложению — opt-in, только имя exe).

### 4.5. Визуализация и эффекты
- Три режима, переключаются на лету:
  - **«Волны»** (по умолчанию) — свой WebGL2-шейдер, «жидкое» поле (domain warping), цвета из настроения трека + акцента. Музыка только плавно ускоряет течение, форма на бит не дёргается (D-107).
  - **«MilkDrop»** — Butterchurn, пресет по вайбу, 30 с / переход 3 с, 🔒 Lock, ♥ «Мои пресеты».
  - **«Видео»** — зацикленные ролики, свои добавляются в интерфейсе.
- Иммерсивный «ночной вайб» и «Полный экран» с названием и кнопками.
- **Живые эффекты** (снег, дождь, туман, листопад, лепестки…) по реальной погоде, ветер сносит частицы; не поверх MilkDrop.
- Сезонные и праздничные **темы** (акцент интерфейса + палитра визуализации), переходы в OKLCH.
- Защита: вспышки ≤ 1 за 10 с, `prefers-reduced-motion`, автоснижение качества по просадке кадров.

### 4.6. Интерфейс и Windows
- Темы: тёмная, светлая, «Оранжевая», «Чёрно-белая», «как в системе»; 17 акцентов + «Авто» из обложки + свой цвет.
- 5 пресетов производительности (Очень слабое … Супермощное) + тумблеры + автоопределение.
- Первый запуск — 4 шага; обучалка; справка (F1).
- Трей (крестик сворачивает, музыка играет), один экземпляр, экономия памяти в трее (WebView усыпляется и выгружается).
- Глобальные хоткеи, **SMTC** (медиа-флайаут Windows), кнопки в превью панели задач, прогресс, Jump List.
- **Виджет рабочего стола** (обложка, управление, мини-визуализация, сон, кольцо фокуса) и мини-бар у панели задач.
- **Bluetooth-меню** внутри плеера (подключить/отключить через драйверный путь, как ToothTray).
- Установщик NSIS без UAC, **портативная версия** (ZIP, с флешки), **бесшовные автообновления** через GitHub Releases, «Открыть с помощью Сиртона», папка Inbox.
- Звуки интерфейса с отдельной громкостью.

## 5. Архитектура

### 5.1. Стек
- **Tauri 2** (ядро на Rust) + **WebView2** (UI): React 19, TypeScript, Vite, Tailwind 4, shadcn/ui, Zustand, TanStack Virtual, dnd-kit, motion, i18next.
- SQLite (`rusqlite`) + FTS5, миграции только вперёд, пути относительные корню медиатеки.
- Аудио: Symphonia + свои декодеры (libopus), WASAPI, Signalsmith (time-stretch, MIT), `rtrb` для lock-free кольца.
- ML: ONNX через `tract`.
- Лицензии: без GPL/AGPL/CC-NC в бинарнике; из GPL-проектов — только идеи.

### 5.2. Принципы
1. **Rust — источник истины**, фронтенд — тонкий слой (снимки + события).
2. **Доменные крейты не знают о Tauri** и не зависят друг от друга — только через трейты в `core` (`WaveRepo`, `QueueSource`, `PlaybackControl`…). Всё запускается без UI через `sirtone-cli`.
3. **Аудио-поток неприкосновенен:** без аллокаций, мьютексов, логов и ввода-вывода.
4. **Прогрессивное улучшение:** трек играбелен сразу после копирования, остальное «доезжает» фоном.
5. Всё тяжёлое — в персистентной очереди задач с приоритетами.
6. Офлайн по умолчанию, единый сетевой слой с лимитерами и мастер-тумблером.

### 5.3. Крейты
| Крейт | Что делает |
|---|---|
| `sirtone-core` | типы, ID, ошибки, события, схема настроек, трейты |
| `sirtone-audio` | декодирование, ресемплинг, DSP, микшер, автомикс, WASAPI |
| `sirtone-playback` | очередь, контексты, шафл, повтор, продолжения, исполнение таймеров |
| `sirtone-library` | SQLite, импорт, раскладка, watcher, дубли, экспорт (единственный владелец БД) |
| `sirtone-recognize` | теги, имена файлов, отпечаток, AcoustID / MusicBrainz / CAA, уверенность |
| `sirtone-analysis` | громкость, пики, BPM/тональность, ML, вайб, сходство |
| `sirtone-search` | нормализация запросов, FTS, нечёткий и смысловой поиск |
| `sirtone-wave` | движок волны: часы, календарь, профили, скоринг, секвенсор, обучение, сезоны, события, темы |
| `sirtone-net` | HTTP, лимитеры, кэш, офлайн-менеджер |
| `sirtone-platform` | SMTC, панель задач, приглушение, звонки, Bluetooth, питание, геолокация |
| `sirtone-cli` | харнесс: play, import, analyze, bench, soak, fuzz, симуляция волны |
| `apps/desktop/src-tauri` | единственный, кто знает Tauri: команды, события, окна, трей, протоколы |

### 5.4. Потоки
UI-поток (окна, трей, хоткеи) · Tokio (IPC, HTTP, таймеры) · **аудио-рендер** (MMCSS Pro Audio, ≤ 50 мкс на колбэк) · поток движка (декодеры, DSP, микшер) · до 2 потоков-декодеров (`catch_unwind`) · пул анализа (below normal + EcoQoS) · воркер волны · один писатель БД + 4 читателя · FS-watcher · платформенные потоки (COM).

### 5.5. IPC и окна
- Типы IPC генерируются из Rust (tauri-specta / ts-rs), ручные TS-типы запрещены; `invoke` — только в `shared/ipc`.
- События батчатся; бинарные потоки (кадры визуализации: 1024×u8 L/R/mono + timestamp + beat_phase, 60 Гц) — через `Channel`.
- Картинки — протоколы `sirtone-cover://` и `sirtone-bg://`.
- Окна: `main`, `widget-desktop`, `widget-taskbar`.
- Фронтенд — feature-sliced (`app / shared / features / entities / widgets`), ни одной строки в JSX (только i18n-ключи).

### 5.6. Данные и файлы
- `library.db` (SQLite, WAL): треки, альбомы, исполнители, плейлисты, признаки треков (~32 числа), журнал прослушиваний `play_event` со снимком контекста, модели волны.
- Хранилище: `Исполнитель / Альбом / Трек`, исходный формат; журнал файловых операций (crash-safe).
- Портативный режим: маркер `sirtone.portable`, всё в папке рядом с exe.
- Конфиги волны (веса, пороги, словари, календарь, палитры) — в `assets/wave/*.json`, не в коде.

### 5.7. Сеть (только эти хосты)
AcoustID (≤ 2/с), MusicBrainz (≤ 0,8/с), Cover Art Archive, Open-Meteo + геокодер, ListenBrainz (≤ 1/с), GitHub Releases. Описательный User-Agent, кэш, backoff, мастер-тумблер «Полностью офлайн».

### 5.8. Качество
- Гейты: `cargo nextest`, `clippy -D warnings`, `fmt`, `cargo deny`, vitest, Playwright + axe, `scripts/check-all.ps1`.
- Харнессы реального приложения: `apps/desktop/e2e/*-quick.mjs` (viz, norm, mix, duck, sfx, fx, theme, sleep, focus, weak, a11y), soak, fuzz, kill-harness импорта.
- Бюджеты: холодный старт ≤ 1,5 с, idle RAM ≤ 250 МБ (с визуализацией ≤ 450), скролл 100 000 строк ≥ 55 FPS, поиск p95 ≤ 80 мс, пересборка волны ≤ 15 мс.
