# Журнал изменений спецификации

Версия спецификации меняется при каждой доработке владельца или принятом ADR: `1.0 → 1.1` (дополнения/уточнения), `→ 2.0` (смена ключевых решений). Код реализует **последнюю** версию.

## 1.2 — 2026-10-15 — решения владельца
- OWN-11 → **D-36**: локальные коммиты после каждой готовой задачи, без push; ветки этапов.
- OWN-12 → **D-37**: идентификатор `studio.serkov.sirtone`, издатель «Серков Studio».
- Ожидаются доработки владельца (следующее сообщение) → войдут в версию 1.3.
