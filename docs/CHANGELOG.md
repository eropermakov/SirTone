# Журнал изменений спецификации

Версия спецификации меняется при каждой доработке владельца или принятом ADR: `1.0 → 1.1` (дополнения/уточнения), `→ 2.0` (смена ключевых решений). Код реализует **последнюю** версию.

## 1.3 — 2026-10-16 — дополнение «Умная волна, сезоны, события и режимы» + аудит проекта

**Дополнение владельца** (`docs/source/Сиртон_ТЗ_дополнение_волна_2026-10-16.md`, разделы 25–38) внесено целиком:
- Исследование по 6+ приложениям на каждую фичу — `01c_RESEARCH_WAVE.md` (W-01…W-11, источники S89–S126); проверены API Open-Meteo, ListenBrainz (через context7 и документацию), Windows (сон, экран, звонки), WebView2.
- Технический дизайн — новый `14_WAVE_ENGINE.md`: крейт `sirtone-wave`, трейты, часы, контекст, вектор признаков (32), профиль волны (JSON), скоринг, секвенсор, обучение, сезоны, события, темы, эффекты, сон, фокус, «Для всех», схема БД (`0002_wave.sql`), IPC.
- Прототип скоринга на синтетической медиатеке — `spikes/S-17-wave-scoring`, отчёт `reports/spike-S-17.md`: пересборка очереди **2,98 мс p95 на 50 000 треков** (цель < 15 мс), 5,94 мс на 100 000, обновление модели 35 нс, квоты ползунка точные, Пасха/Масленица 2026–2030 и солнцестояния 2027 совпали с таблицами.
- ТЗ: новый раздел `02` §26 — 72 требования (FR-WENG, FR-LEARN, FR-SEAS, FR-EVT, FR-THEME, FR-FX, FR-SLEEP, FR-FOCUS, FR-NOV, FR-ALL), NFR-PERF-004, NFR-PRIV-001, сценарии **AT-13…AT-24**; уточнены FR-PLAY-011/014/015, FR-WAVE-003/006, FR-VIZ-006/009, FR-CTX-002, FR-UI-003/008, FR-PERF-004, FR-ONB-001, FR-SET-001, FR-SHELL-006/009, FR-WIN-003, §23.
- Решения D-38…D-53; **17 вопросов владельцу Q-1…Q-17** с предложениями (`10` §5) — в т.ч. противоречия с основным ТЗ: журнал прослушиваний vs «только агрегат» (Q-9), окно смены сезона ±10 дней vs пример «20 ноября 0,7/0,3» (Q-10, предложено ±21 день), правило автоснижения (Q-11), «Частота» vs ползунок (Q-12), «Занятие» vs режимы (Q-13).
- Архитектура, звук, библиотека, UX, Windows, качество, дорожная карта: `03`, `04`, `05`, `06`, `07`, `08`, `09` (эпики E1.10, E3.8–E3.10, E4.8–E4.11, E5.8–E5.10; спайки S-17 ✅, S-18, S-19; OWN-13, OWN-14), бэклог `13` (+31 задача: T1.29–T1.31, T2.19, T3.23–T3.32, T4.18–T4.24, T5.13–T5.18, T7.9; всего 163).
- Важная находка: на ноутбуке владельца нет классического сна S3 (только Modern Standby) → «перевести ПК в сон» после таймера делается иначе (D-48, спайк S-18).

**Аудит проекта** (исправлено):
- Версии в заголовках документов и в `CLAUDE.md` (было «1.0»); `09` §1 — устаревшее «коммиты только по команде, коммитов нет» → D-36; `08` R-01 ссылался на `09` §4 вместо §5; `02` §0 ссылался на сценарии «§14» вместо §24.
- `12` §3.5: трейт `JobHandler` с ассоциированными типом и константой нельзя хранить как `dyn` — добавлена объектно-безопасная обёртка `ErasedJob`.
- Гейты качества падали бы на первом же коммите Этапа 0 (D-55): `cargo nextest` без тестов завершается с кодом 4 → `--no-tests=warn`; `cargo-deny` ругался бы на собственные крейты (`UNLICENSED`) и path-зависимости → `licenses.private.ignore`, `allow-wildcard-paths`; добавлен `clippy.toml` (unwrap/expect в тестах); `pwsh` не установлен, а политика выполнения скриптов по умолчанию запрещает `.ps1` → запуск `powershell -ExecutionPolicy Bypass -File` (только для процесса).
- Двойное приглушение на звонках (Windows 80 % + наше) → отказ от системного для своей сессии + уведомления о звонках (D-49).
- Не определённый хост «геолокации по IP» → служба местоположения Windows (D-54).
- WebView2 при сворачивании в трей теперь сразу усыпляется (`TrySuspend`) до уничтожения через 60 с (D-52).
- «Забытые» в «Частоте»: 90 → 60 дней (согласовано с дополнением); ночной вайб больше не мешает сон-таймеру погасить экран.
- `03` §5.5 / `12` §4.7: коды ошибок `NotSupported`, `InvalidConfig`; `12` §2.2: `spikes/*` исключены из workspace.
