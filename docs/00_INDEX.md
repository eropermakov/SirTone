## Ключевые решения в одну страницу

1. **Tauri 2 + Rust-ядро + WebView2-UI** — повторяет Spotify/Plexamp/Roon (ядро отдельно от веб-UI) и рабочие Tauri-плееры; критерии отказа — `09` §5.
2. **SQLite + FTS5, пути относительные**; foobar2000 v2 тоже ушёл от «базы в памяти» к SQLite.
3. **Автомикс — лестница L0–L3** (gapless → срезка тишины → перекрытие по огибающей громкости → beatmatch): Apple, VirtualDJ, MPD MixRamp, Plexamp, Mixxx, djay; альбомы не микшируются.
4. **Визуализация — три режима** (цветовые «Волны» как у «Моей волны», MilkDrop на Butterchurn, Видео как Spotify Canvas); данные — 1024×u8 L/R/mono + timestamp, как у WMP/iTunes/Butterchurn; пресеты по умолчанию — как у projectM.
5. **Распознавание — взвешенное расстояние + 3 зоны** (beets/Picard): нет уверенности → «Неизвестные».
6. **Умные плейлисты — схема Navidrome `.nsp` + семантика Apple**; продолжение плейлиста — как Roon Radio/Spotify Smart Shuffle (∞, «+»/«−»), только из своей библиотеки.
7. **Нормализация −14 LUFS по умолчанию** (Спотифай-трио −19/−14/−11), по альбому; **EQ 10 полос**; **приглушение** по сессиям Core Audio.
8. **Bluetooth — путь ToothTray** (`IKsControl`/`KSPROPSETID_BtAudio`) вместо `BluetoothSetServiceState`; **панель задач** — превью-кнопки + прогресс + Jump List + SMTC (Deskband в Win11 невозможен).
9. **Лицензии:** без GPL/AGPL/CC-NC; time-stretch — Signalsmith (MIT); модели Essentia (NC) не включаем.
10. **Визуал — ваш**; до макетов — нейтральный каркас и токены.
