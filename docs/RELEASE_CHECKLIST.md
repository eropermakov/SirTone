# Release checklist: Windows Beta и 1.0

Релиз создаётся только по явному решению владельца. Ни чекбокс, ни успешная CI-сборка не дают разрешения на push, тег или публикацию.

## Общие обязательные условия

- [ ] Рабочее дерево классифицировано; в коммиты не попали ключи, кэши, пользовательская музыка, базы или сертификаты.
- [ ] `pnpm typecheck`, `pnpm lint`, `pnpm test`, `cargo fmt --all -- --check`, Clippy, Rust tests и `cargo deny check` прошли на финальном коммите.
- [ ] Все блокирующие advisories либо исправлены, либо владелец формально остановил выпуск.
- [ ] Версия, канал и короткий commit Build ID согласованы и видны в диагностике.
- [ ] `THIRD_PARTY_NOTICES.txt`, лицензии и сетевые разрешения сверены; нет GPL/AGPL/CC-NC в бинарнике.

## Windows Beta

- [ ] Установщик NSIS, portable, запуск второго экземпляра, WebView2 и удаление проверены изолированно.
- [ ] Подпись установщика и обновления проверена; ключи не находятся в Git или в CI-логе.
- [ ] Установлено разделение Development/Beta/Stable; Stable-пользователь не переводится в Beta автоматически.
- [ ] Проверены таймаут, повтор и rollback обновления; база, плейлисты, настройки и пространства сохраняются.
- [ ] Feedback API развёрнут за HTTPS, rate limit/dedupe имеют persistent TTL storage, SMTP credential в secret manager, тестовое письмо получено в `sir.kov.mail@gmail.com`.
- [ ] Форма обратной связи, ZIP и ручной fallback пройдены на чистом Windows-ПК.
- [ ] Владелец прошёл пункты Windows из `MANUAL_ACCEPTANCE.md`, включая 24-часовой тест.

## Windows 1.0 дополнительно

- [ ] Нет известных P0/P1 дефектов беты; changelog и известные ограничения опубликованы.
- [ ] Выполнены повторная чистая установка, обновление с последней беты и план rollback.
- [ ] Подтверждены политики поддержки, мониторинга минимального delivery-журнала и обработки недоставленных обращений.

## iPhone

- [ ] macOS/Xcode-сборка, dSYM и соответствующий способ символикации native crashes подготовлены.
- [ ] Пройдены два независимых физических iPhone из `MANUAL_ACCEPTANCE.md`; это не заменяется симулятором.
- [ ] Проверены HTTPS feedback, Mail fallback, Share Sheet, разные Installation ID и сохранение ID при обновлении.
- [ ] Подписывание/продление на 7 дней проверено владельцем, если используется free Apple ID.

## Перед публикацией

- [ ] Владелец явно одобрил канал, артефакты, подписи и публикацию.
- [ ] Только после этого: `scripts/release.ps1`, тег и GitHub Actions по утверждённому процессу.
