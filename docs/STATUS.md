# Состояние SirTone

Сверено 2026-11-18 по Git, исходникам, отчётам этапов и опубликованным выпускам. Это сводка состояния, не новая спецификация. Требования — `02_TZ.md`, решения — `10_DECISIONS.md`, задачи — `13_BACKLOG.md`. При изменении статуса задачи обновлять эту страницу и соответствующий отчёт; старые записи о ходе работ сохранять как историю.

## Следующие функции по принятому плану

`mobile/full-port.md` и `mobile/README.md` описывают полный порт; их ранние колонки «сейчас» — исторические. EQ, часть автомикса, обстановка, «Волны» и MilkDrop уже реализованы, повторно их не создавать.

Остаток включает «Фокус», событийные сценарии, умные плейлисты и смысловой поиск, инструменты медиатеки, язык, пресеты производительности, быстрые действия, самопродление подписи и оставшиеся эффекты. Объём каждой следующей задачи сверять с кодом и бэклогом. IDEA-01 «Обложка» остаётся идеей вне утверждённого плана.

## Проверки и выпуск

Workflow-файлы лежат в `.github-pending/workflows` и `ci`; GitHub Actions при аудите не вернул запусков. Наличие YAML не означает работающий CI. Последние выпуски сделаны локальными скриптами `release.ps1` и `release-ios.ps1` (WSL). Не активировать публикацию или менять токен GitHub попутно с исправлением кода.

Приоритет: восстановление обновлений → проверки последнего iPhone → суточный прогон Windows и П3 → анализ/виджет/мобильная приёмка → оставшийся порт. Для аппаратных проверок нужны соответствующие устройства; даты и результаты фиксировать по факту, не по плану.
