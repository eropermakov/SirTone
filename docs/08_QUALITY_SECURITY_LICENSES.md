## 4. Безопасность

**Модель угроз (главное):**

1. **Недоверенные аудиофайлы** (с флешек): парсеры только на memory-safe Rust (symphonia, lofty); C-зависимости — libopus (+ опционально ONNX Runtime) и libwebp (только **кодирует** наши уже декодированные пиксели обложек в WebP-кэш; недоверенные байты в неё не попадают); изображения обложек декодирует `image` (Rust), с лимитом 40 Мпикс до декодирования; `catch_unwind` на декодерах; лимиты на размеры тегов/обложек; fuzz-тест (cargo-fuzz) декодеров на корпусе — этап 7; ffmpeg-sidecar — отдельный процесс, **Job Object** (лимит памяти/времени), без сети.
2. **Пути:** `LibraryPath::parse` (относительные, без `..`, без reserved-имён, NFC); операции вне корня запрещены, кроме источников импорта (drag-drop) и выбранной папки экспорта; защита от симлинков/junction при обходе (не следовать).
3. **SQL:** только параметры; смарт-плейлисты — белый список полей/операторов → SQL (нет конкатенации пользовательских строк).
4. **WebView:** нет удалённого кода/CDN; строгий CSP; DevTools только debug; внешние ссылки — через `opener` (только `https`); capabilities минимальны; плагины `fs/shell/http` не выдаются фронтенду.
5. **Обновления:** подпись Ed25519 (minisign) проверяется клиентом; без ключа обновить нельзя; HTTPS обязателен.
6. **Секреты:** AcoustID `client`-ключ — публичный по назначению (встраивается), ключ подписи обновлений — только в секретах CI + офлайн-копия; никаких токенов в репозитории (pre-commit gitleaks).
7. **Повышение привилегий:** приложение не требует UAC (NSIS per-user); админ-права не запрашиваются ни для одной функции (BT-путь 2 — проверить, при необходимости отключить).
8. **Логи:** без содержимого файлов и полных путей пользователя в «Экспорте диагностики» (обезличивание имени профиля).

**Приватность:** телеметрии и аналитики **нет**. Журнал прослушиваний (`play_event`), модели вкуса и обратная связь — только в локальной `library.db`, не уходят в сеть, не включаются в «Экспорт диагностики», удаляются «Сбросить обучение» (NFR-PRIV-001). Карта исходящих запросов (единственная):

| Куда | Что уходит | Когда | Отключается |
|---|---|---|---|
| api.acoustid.org | отпечаток (≤120 с), длительность, ключ приложения | фоновое распознавание | офлайн-режим |
| musicbrainz.org, coverartarchive.org | MBID | то же | то же |
| api.open-meteo.com | координаты (округл. до 0,01°) | погода, раз в 30–60 мин | «Контекст: погода», «Эффекты: по сезону/выкл» / офлайн |
| api.listenbrainz.org | MBID записей (пачкой), User-Agent | популярность для «Для всех», раз в месяц на трек | офлайн-режим / тумблер «Популярность из интернета» |
| geocoding-api.open-meteo.com | строка города | при ручном выборе | то же |
| служба местоположения Windows (опция «Определить автоматически», D-54) | запрос идёт через Windows, не от Сиртона; координаты округляются до 0,01° перед сохранением | по явному нажатию | по умолчанию выкл.; разрешение — в настройках конфиденциальности Windows |
| github.com (Releases) | версия/архитектура в URL, IP | раз в сутки + вручную | «Автопроверка обновлений» |

## 6. CI/CD

**`ci.yml`** (windows-latest, на PR и push): setup Node 24 + pnpm + Rust stable (кэш `rust-cache`) → `cargo fmt --check` → `cargo clippy --workspace --all-targets -- -D warnings` → `cargo deny check` → `cargo nextest run` → `pnpm install --frozen-lockfile` → `pnpm lint` → `pnpm typecheck` → `pnpm test` → проверка IPC-биндингов → `pnpm tauri build --debug` (smoke) → Playwright component tests → артефакты.
**`release.yml`** (тег `v*.*.*`): `tauri-action` (NSIS, подпись артефактов обновления, `latest.json`) → job портативного ZIP (exe + `sirtone.portable` + Fixed Runtime WebView2 по закреплённой версии/хэшу) → `SHA256SUMS` → публикация релиза. Секреты: `TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` (+ подпись кода, если выбрана).
**Версионирование:** SemVer; Conventional Commits; changelog из коммитов (`git-cliff`).
**Автоматизация владельца ✅:** `scripts/release.ps1` — поднимает версию во всех манифестах, коммитит, тегирует, пушит → CI собирает и публикует; пользователю остаётся нажать «Обновить». Требует авторизованный `gh`/git (OWN-04).
