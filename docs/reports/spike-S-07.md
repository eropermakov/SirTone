# Спайк S-07 — модель жанра и настроения в приложении: EfficientAT `mn10_as` + `tract`

- **Дата:** 2026-10-18, Этап 3 · **Задачи:** T3.8 (B2), T3.9 (B3) · **Требования:** REC-010/011 · **ADR:** D-12, D-84, D-85
- **Критерии (`09` §4, `04` §10):** лицензия без NC; работает без сети и без GPU; ≤ 1 с на трек на модель; установщик ≤ 40 МБ (P-14).

## 1. Что сделано
- **Модель:** EfficientAT MobileNetV3 `mn10_as` (MIT, © 2022 Florian Schmid; AudioSet, 527 классов, mAP 0,471, 4,88 млн параметров). Веса — `mn10_as_mAP_471.pt` из официального релиза репозитория (sha256 в `assets/models/MODELS.md`), загружены с `weights_only=True` в отдельной папке на D:, Python запускался с `-I`.
- **Экспорт** (`spikes/S-07-model/export_mn10.py`): PyTorch 2.14 CPU → ONNX opset 17, вход `mel` [1, 1, 128, 1000] (окно 10 с, 32 кГц), выходы `logits` [1, 527] и `embedding` [1, 960]. Сверка ONNX ↔ PyTorch (onnxruntime) — 1,0·10⁻⁵.
- **Фронтенд на Rust** (`spikes/S-07-model/src/main.rs`, затем `crates/sirtone-analysis/src/b2.rs`) — точная копия `AugmentMelSTFT` в режиме оценки: предыскажение [−0,97, 1] → STFT n_fft 1024, окно Ханна 800 (непериодическое, по центру), шаг 320, `center` с отражением → мощность → мел-банк Kaldi 128×513 (экспортирован из torchaudio) → ln(x + 10⁻⁵) → (x + 4,5) / 5.
- **Инференс:** `tract-onnx` (чистый Rust, MIT OR Apache-2.0) — ни сети, ни GPU, ни нативных DLL.

**В приложении** (T3.8/T3.9): два окна по 10 с на 30 % и 65 % длительности (короче 10 с — весь трек; длительность из тегов неверна — запасное окно 10–20 с), передискретизация в 32 кГц (sinc Ланцоша, 16 лепестков, фазы рациональных частот — таблицей), средние вероятности классов → вайб по правилам `assets/vibe/b3.json` (D-85); эмбеддинг 960 → 64 (фиксированная гауссова проекция, закреплена тестом) → int8 в `track.embedding` (для T3.14 «похожее»).

**P-11 на реальной музыке** (`sirtone-cli analyze`, MP3 из медиатеки владельца, только чтение): весь фоновый проход (B0 + отпечаток + B1 + B2/B3, одно декодирование) — **1,3–2,8 с** на трек 0:35–5:48. Цель P-11 (2 с) превышена на длинных треках, предел (4 с) соблюдён. Первая версия с прямым sinc давала до 3,8 с.

**Разброс вайба** (те же треки): рок с вокалом («Король и Шут») — жанр «рок/метал» 0,53–0,72, вокал 0,67–0,79, энергия ≈ 0,9; инструментальная электроника — «электроника» 0,75–0,93, вокал 0,10–0,24, акустичность ≤ 0,1; эмбиентные треки — «спокойное» 1,0 и низкое возбуждение (0,23–0,25). Рэп: Ja Rule — «хип-хоп/R&B» 0,47, вокал 0,82; Knoc-Turn'al «Muzik» — **ошибка**: «рок/метал» 0,51 при хип-хопе 0,29 (вокал 0,88 верно). Значения расходятся по трекам, а не сбиваются к средним; качество по меткам — после калибровки (D-85). Жанр из тегов всё равно главнее модели.

## 3. Вывод
`mn10_as` + `tract` проходят по лицензии, скорости и размеру — принят для B2 (D-12, D-84). Альтернатива `ort` (ONNX Runtime) не нужна: нативная DLL, лишние ~10 МБ, выигрыш в скорости не требуется.

**Не сделано / дальше:** калибровка правил B3 на открытых размеченных наборах (MTG-Jamendo moodtheme, FMA — локально, не в репозитории) и на золотом наборе владельца (OWN-08); инструмент «Калибровка» (T3.9); язык вокала (ru/иностранный) по звуку — пока только «без слов» по вокалу и письменность названия.
