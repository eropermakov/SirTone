# Спайк S-05 — виртуализация 100 000 строк с обложками

- **Дата:** 2026-10-16, Этап 0 · **Задача:** T0.19 · **Критерий (`09` §4):** ≥ 55 FPS, RAM ≤ 300 МБ · **Риски:** R-01, R-18
- **Вопрос:** тянет ли WebView2 (движок Edge) список/сетку на 100 000 элементов с обложками на `@tanstack/react-virtual` 3.14.19.

## 1. Что сделано
Код: `spikes/S-05-virtual-list/` (Vite + React 19, вне workspace; обложки — `make-covers.sh`).
- **Список:** 100 000 строк TrackRow по `DESIGN.md` §9 (52 px, номер, обложка, название + исполнитель, альбом, длительность), `translateY`, overscan 8.
- **Сетка:** AlbumCard 184 px (обложка 184 + 2 строки), ≈ 8 300 альбомов.
- **Обложки:** 400 WebP-файлов, но у каждого альбома свой URL (`?id=`) → браузер декодирует каждую обложку заново, как будет с `sirtone-cover://<hash>`. `loading=lazy`, `decoding=async`.
- **Замер** (`measure.mjs`, `plateau.mjs`): Edge 155 через Playwright (`channel: msedge`, тот же движок, что WebView2), окно 1548×860, прокрутка с постоянной скоростью из `requestAnimationFrame` (1 500 / 6 000 / 30 000 px/s — от колёсика до «броска»), интервалы кадров; память — сумма `PrivateMemorySize` всех процессов этого Edge минус пустая страница. Сборка — production (`vite build`).

## 3. Выводы
- **≥ 55 FPS выполнено:** 60 FPS во всех режимах, включая «бросок» 30 000 px/s. Решение `03` §11 (react-virtual, фиксированная высота, `transform`) подтверждено; запасной план (пагинация) не нужен.
- **RAM ≤ 300 МБ — на грани, но с потолком:** рост ограничен кэшами декодированных картинок и растра Chromium (плато ~270 МБ). Обязательно для реализации: **миниатюры под размер ячейки** (`covers\<size>\` из `03` §8: 80 px для строк, 368 px для карточек на 200 % DPI), не исходные обложки — это −65 МБ. Дополнительно при сворачивании в трей — `MemoryUsageTargetLevel = Low` / `TrySuspend` (D-52) отпускает кэши.
- Отказ от Tauri по критерию производительности списков (`09` §5) не нужен.

## 4. Не проверено
- Внутри реального приложения с данными из SQLite (страницы по 100 через IPC, S-15 показал ≤ 1 мс на страницу) — Этап 2 (T2.x); 
- Слабое железо/встроенная графика и 200 % DPI — у владельца.
