# S-21 — компактный импорт Opus

Дата: 2026-11-17 · задача: T8.4 · статус: пройден локальный технический спайк; упаковка sidecar не принята.

## Результат

Локальный FFmpeg 9.0.1 создал из синтетического WAV 48 кГц / 10 с файл Opus с `libopus -b:a 96k`.

| Вход | Выход | Размер входа | Размер выхода | Экономия |
|---|---|---:|---:|---:|
| WAV | Opus | 960 078 байт | 154 592 байта | 83,9 % |

`ffprobe` подтвердил `codec_name=opus`. SirTone уже декодирует Opus через `symphonia-adapter-libopus`, поэтому выходной файл совместим с текущим проигрывателем.

## Решение для реализации

Использовать отдельный процесс FFmpeg только из закреплённой LGPL-сборки, с Job Object, лимитами времени/памяти, без сети и с проверкой SHA-256 ресурса. Сборка, установленная у разработчика, не является ресурсом приложения и не может быть упакована без проверки лицензии и происхождения. В `import.rs` кодирование вставляется вместо `copy_verified` внутри `probe_and_copy`, до существующей проверки staging, хэша и journal-place.
