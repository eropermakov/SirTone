## Безопасность
- **Не запускать собранный установщик или деинсталлятор на ноутбуке владельца** — оба для текущего пользователя и обновили бы/удалили его установленный Сиртон. «Удаление сохраняет медиатеку» проверяется чтением хуков NSIS; чистая ВМ — проверка владельца (в Win11 Home нет Песочницы).
- **CI и подпись:** секреты GitHub не добавлять, GH_TOKEN не трогать — только перечислить, что нужно. `release.yml` запускается только вручную (`workflow_dispatch`) или по тегу `v*`, никогда по push (репозиторий приватный — минуты владельца). Тег для проверки не пушить.
- **Репозиторий остаётся приватным**, даже если бесплатная подпись SignPath требует публичного — решение владельца.
- **WebView2 Fixed Runtime** (~180 МБ) — скачивается скриптом в отдельную папку с проверкой подписи Authenticode, в репозиторий не коммитится.
- **`release.ps1` не запускать** — выпуск только по команде владельца.
- Портативная версия проверяется в временной папке с маркером; флешка (S-13) — проверка владельца.
