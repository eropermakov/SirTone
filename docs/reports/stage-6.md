- **Видимость репозитория не меняем.** Он публичный (D-76; проверено `gh repo view` 2026-10-21) — на этом держится канал обновлений: установленные копии берут `latest.json` без авторизации. (В CLAUDE.md написано «приватный» — устарело, файл правит владелец.)

- **`release.ps1` не запускать** — выпуск только по команде владельца.
- Портативная версия проверяется в временной папке с маркером; флешка (S-13) — проверка владельца.
