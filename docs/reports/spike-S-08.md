# Спайк S-08 (часть A) — темп и тональность: `stratum-dsp` 1.0

- **Дата:** 2026-10-18, Этап 3 · **Задача:** T3.7 (анализ B1) · **Требования:** REC-001 · **ADR:** D-11
- **Критерии (`09` §4):** BPM ±2 ≥ 85 % на файлах с известным темпом; ≤ 0,6 с на трек (`04` §10, B1).
- **Часть B** (растяжение Signalsmith, прототип автомикса на 30 парах) — с автомиксом (Этап 4), здесь не делалась.

## 1. Что сделано
Код: `spikes/S-08-bpmkey/` (вне workspace). Корпус синтезируется там же, детерминированно: 48 треков по 3 мин, ударные (бочка на каждую долю, малый на 2 и 4, хэт на восьмые) в темпе 62…188 BPM, аккорды по такту и бас; все 24 тональности по два раза (мажор I–V–vi–IV, минор гармонический i–iv–V–i — первая версия с натуральным минором i–VI–III–VII неотличима от параллельного мажора, это ошибка корпуса, а не анализатора). Референсы — `01a` §D (Mixxx, Traktor, djay, VirtualDJ, Spotify, Mixed In Key).

## 2. Результаты (`cargo run --release -- <режим>`, Ryzen 7 5800H)

| Режим | BPM ±2 как есть | после 70–180 (×2/÷2) | с точностью до октавы | тональность точно | время на 3-мин трек |
|---|---|---|---|---|---|
| по умолчанию, весь трек 44,1 кГц | 70,8 % | 81,2 % | 97,9 % | 77,1 % | 6 250 мс |
| без мультиразрешения и band fusion | 70,8 % | 85,4 % | 100 % | 77,1 % | 3 600 мс |
| то же, **первая минута** (10–70 с) | 85,4 % | 91,7 % | 100 % | 70,8 % | 1 161 мс |
| **первая минута, 22,05 кГц** | — | **97,9 %** | **100 %** | 62,5 % | **593 мс** |
| 30 с, 44,1 кГц | — | 85,4 % | 100 % | 66,7 % | 567 мс |

- **Темп** верен с точностью до октавы почти всегда; ошибки — ×2/÷2 (как у всех: Traktor, VirtualDJ — `01a` §D). Приведение к **70–180 BPM** (диапазон Traktor/djay) убирает большую часть; 170–190 BPM остаются как 85–95 (неустранимо без ручного ×2).
- **Тональность:** мажоры — 100 %, ошибки только в минорах (путает с одноимённым мажором); на реальной музыке README заявляет 72 %.
- **Уверенности `bpm_confidence` / `key_confidence` неинформативны:** у верных ответов 0,00–0,3, у октавных ошибок даже выше (0,5–0,67); `key_clarity` всегда ≈ 0,65. Порог «применять только при `conf ≥ 0,8`» из `04` §10 отбросил бы **все** результаты.
- **Нотация:** `Key::numerical()` крейта — не Camelot (у него C-мажор = «1A», в Camelot — 8B); считаем Camelot сами (тест в спайке).
- **Зависимости:** `rayon` объявлен, но в коде не используется — дополнительных потоков нет, фоновый приоритет анализа сохраняется; тянет вторую `symphonia` 0.5 (рядом с нашей) — только размер бинарника.

## 3. Выводы → D-11
- **B1 = `stratum-dsp` 1.0** в облегчённом режиме: моно, ≈ 22 кГц (целочисленное прореживание), **первая минута после 10 с** (короткий трек — целиком), без мультиразрешения и band fusion: **97,9 % BPM ±2 (после 70–180), 593 мс** — в бюджете B1 (≤ 0,6 с).
- Темп приводится к 70–180; уверенность крейта не используем как порог; в волну темп идёт как мягкий признак, в автомикс (L3, Этап 4) — со своей проверкой по сетке битов.
- Тональность хранится в Camelot с уверенностью крейта «как есть»; в волне — признаки 5–7 (круг квинт, лад).

## 4. Не проверено
- **Реальная музыка** (живые барабаны, переменный темп, рубато, классика) — синтетика их не моделирует. Нужен золотой набор владельца с известными BPM и тональностью (**OWN-08**); до него метрика «BPM ±2 ≥ 85 %» подтверждена только на синтетике.
- **Устойчивость тональности:** одна синтетическая мелодия (3:20) в FLAC и MP3 320k дала 8A и 2A при одинаковом темпе 120 (`sirtone-cli analyze`, P-11: 0,94–0,98 с на трек) — тональность на неоднозначном материале нестабильна; хранится с уверенностью крейта, в волне весит как мягкий признак.
- Часть B (растяжение и прототип автомикса) — Этап 4.
