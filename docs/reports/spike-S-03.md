# Спайк S-03 — внешний drop файлов и перетаскивание внутри страницы

- **Дата:** 2026-10-16, Этап 0 · **Задача:** T0.17 · **Требования:** LIB-003, IMP-001 · **ADR:** D-07
- **Вопрос (`09` §4):** работают ли одновременно нативный drop файлов (`dragDropEnabled: true`) и перетаскивание внутри страницы; приходят ли пути корректно (юникод, длинные).

## 1. Что сделано (в приложении, не в отдельном прототипе)
- Нативный drop: `WindowEvent::DragDrop(Drop { paths })` обрабатывается **в Rust** (`main.rs` → `playback::open_paths`); пути не проходят через WebView. Тот же вход — командная строка и второй запуск (single-instance) — даёт проверяемый без мыши путь.
- Перетаскивание внутри страницы — на pointer-событиях с `setPointerCapture` (как `@dnd-kit` pointer-сенсоры, D-07): ползунки перемотки и громкости (`shared/ui/Slider.tsx`).

## 3. Вывод
**D-07 подтверждено:** нативный drop — в Rust, внутреннее перетаскивание — только pointer-события (`@dnd-kit/core` с pointer-сенсорами на Этапе 2). Критерий отказа от Tauri (a) из `09` §5 не срабатывает. Остаётся проверка мышью у владельца (уже в чек-листе `stage-0.md`). Оверлей «бросьте сюда» при наведении файла — `DragDropEvent::Enter/Leave`, Этап 2 (E2.3).
