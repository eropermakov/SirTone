**Критерии отказа от Tauri:**
- (a) drop файлов + внутреннее перетаскивание — **не срабатывает**: drop в Rust, pointer-перетаскивание работает при включённом drop (S-03).
- (b) слой виджета — **пока не оценить**: спайк S-09 по плану на этапе виджетов; запасной путь (нативное окно виджета) описан в `07`.
- (c) кадры визуализации ≥ 30 Гц — **не срабатывает**: 60 Гц без потерь, 60 FPS MilkDrop и «Волны» на встроенной графике (S-04).

**Замеры этапа (все отчёты — `docs/reports/spike-S-*.md`):**
