# Спайк S-19 — слой живых эффектов (WebGL2)

- **Дата:** 2026-10-20, Этап 4 · **Задачи:** T4.19 (спайк), T4.20 (`FxEngine`) · **Требования:** FR-FX-005/007, P-18 · **ADR:** D-46
- **Критерии (`09` §4):** кадр p95 ≤ 20 мс вместе с визуализацией на iGPU владельца при уровне 3; GPU эффектов ≤ 3 мс (уровень 2 — ≤ 1,5 мс, P-18). Запасной вариант — общий canvas с «Волнами» (без MilkDrop), меньше частиц.

## 1. Что сделано
Сразу рабочий `FxEngine` (`apps/desktop/src/shared/viz/fx.ts`), а не отдельный прототип: отдельный `<canvas>` WebGL2 над визуализацией и под `artwork-scrim`, `pointer-events: none`. Частицы — один статичный буфер семян на 5 000 инстансов, движение `f(seed, t, ветер, дыхание)` в вершинном шейдере, один `drawArraysInstanced`; туман и тени облаков — fBm-шум на холсте в ¼ разрешения. Замеры — `apps/desktop/e2e/fx-quick.mjs` на настоящем приложении (изолированная папка данных, играет волна).

**Машина:** ноутбук владельца, `ANGLE (AMD, AMD Radeon(TM) Graphics (0x00001638) Direct3D11)` (Ryzen 7 5800H, iGPU Vega 8), окно 1228×736 CSS-px при масштабе 225 % → холст эффектов **2763×1656** (4,6 Мпикс — больше 1080p, оценка с запасом). `EXT_disjoint_timer_query_webgl2` в WebView2 **доступен** — GPU-время измерено им (медиана 60 кадров), не разницей кадров.

- Кадр (≈ 57 кадров/с у дисплея этого ноутбука) **не меняется** ни в одном режиме даже при 5 000 частицах — затраты эффектов меньше шума измерения.
- GPU эффектов — **0,02–0,33 мс**: в 5–75 раз ниже бюджета P-18 (1,5 / 3 мс). Самое дорогое — крупные листья на уровне 4.
- Контекстов GL максимум два (визуализация + эффекты); при видео — один.
- `gl.finish()` как замер в ANGLE/D3D11 не ждёт GPU (показал 0) — для будущих замеров только timer query.

## 3. Выводы → D-46
- **Отдельный слой поверх визуализации** подтверждён: укладывается с огромным запасом, не требует правки Butterchurn, одинаково работает над «Волнами», MilkDrop и видео. Запасной вариант (общий canvas) не нужен.
- Бюджеты §13.3 оставляем как в ТЗ (300 / 1 500 / 5 000); деление пополам при MilkDrop ≤ 3 сохраняем ради слабых iGPU, хотя здесь оно не понадобилось.
- Не сделано / упрощено (в D-46): «капли по стеклу» с преломлением фона — отдельный слой не видит визуализацию, для этого нужен общий кадр; дождь — косые струи. «Размытие» уровня 4 — мягкость дальней плоскости в шейдере частицы, не постобработка. Статичная версия — тот же кадр частиц в фиксированный момент (без «инея по краям»).
