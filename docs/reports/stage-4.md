- [x] T4.2 «Волны» (FR-VIZ-003/006/010, `06` §7.2):
  - **Шейдер** WebGL2: доменное искажение fBm в 2 прохода (копия: Inigo Quilez «Domain warping» — классическое «жидкое» поле, из которого сделан фон Apple Music/AMLL, `01a` §B.3), 4 цвета, виньетка, зерно. **Что двигает** — копия Яндекс «Моя волна» (`01a` §B.3): такт по фазе бита → амплитуда искажения (геометрия, не яркость), bass → искажение, treble → мелкие блики, ♡ → импульс, курсор/клик → белые импульсы.
  - **Палитра** OKLCH: цвет трека по вайбу (углы valence×arousal: грусть 265°, злость 20°, радость 50°, спокойствие 170°; хрома ∝ arousal 0,08–0,20; светлота по valence 0,35–0,75) → `mix_oklab` с «Цветом вашей музыки» (0,35) → с акцентом темы (0,25, тумблер `viz.follow_theme_accent`); смена трека — плавно 1,5 с. Без анализа — цвет обложки, без обложки — акцент. Все числа — `assets/viz/waves.json`.
  - **Палитра обложки** по `DESIGN.md` §4 «Авто-режим» (64 px, OKLab, без почти чёрных/белых, k-means k = 5, ранг `доля × (0,3 + хрома)`), кэш в `cover.palette` (колонка была, но не заполнялась). **Цвет коллекции** — взвешенные по прослушиваниям кластеры палитр 120 самых слушаемых альбомов (отклонение от `06` §7.2: вместо «среднего + кластеры» берётся главный кластер — среднее разных обложек выходит серым), пересчёт не чаще раза в 10 мин. Команда `viz_colors`.
  - **Минимальный вариант** (FR-VIZ-010): 2 цвета, без бликов — настройка `viz.minimal` (тумблер в UI — вместе с T4.5/T4.7) и уровень 1.
  - **Уровни**: 0 — без WebGL, размытый градиент 2–3 цветов обложки (blur 100 px, дрейф 25 с, `DESIGN.md` §9); 1 — 30 FPS ×0,5, минимальный; 2 — 45 FPS ×0,6; 3 — 60 FPS ×0,75; 4 — 60 FPS ×1. Нет WebGL2 / потерян контекст → градиент.
  - **Безопасность**: вспышки ≤ 1 за 10 с (единственный подъём яркости — ♡/клик, не чаще раза в 10 с; бит — только геометрия; блики мелкие и сглажены); `prefers-reduced-motion` — один неподвижный кадр на трек, без импульсов и без подачи кадров.
  - **Цикл**: рисование по `requestAnimationFrame` из jitter-буфера 2 кадра (`06` §7.6), не на каждое сообщение; окно скрыто → подача кадров остановлена, рисование на паузе (полная пауза/деградация — T4.6).
  - **Экран**: «Моя волна» в тёмной области (`data-theme="dark"` + та же лестница #333333 D-75) — текст алебастровый поверх визуализации (`DESIGN.md` §9), `artwork-scrim` под контентом; сырые цвета — только в фоне.
