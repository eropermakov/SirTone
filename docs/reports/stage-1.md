## Решения и рамки (до кода)
- **Корень библиотеки** — уже решено в `03` §8.2: по умолчанию `%USERPROFILE%\Music\SirTone`, выбор на первом запуске; в настройках `library.root = null` до выбора. Портативный режим — `<exe_dir>\Library\`. Без выбора пользователя в библиотеку ничего не копируется.
- **Изоляция тестов:** переменная `SIRTONE_DATA_DIR` (AppData) и временный корень библиотеки для всех тестов на реальном приложении — чтобы проверки не трогали медиатеку и `library.db` владельца. Делается вместе с T1.9, до первого кода импорта.
- **Границы крейтов (`03` §3.1):** `sirtone-library` — единственный владелец SQLite, импорт и журнал файлов; проба формата (`audio`), теги (`recognize`), тип носителя (`platform`) приходят через трейты `core` (`MediaProbe`, `TagReader`, `VolumeInfo`), реализации подключает `app`. Доменные крейты друг от друга не зависят.
- **Миграция `0001`** — DDL `03` §7 + индексы S-15; `0002_wave.sql` (`14` §18.1) — следом, в T1.30.
