Бета трека с весами сигналов по таблице §8.1 (лайк 1,0; пропуск < 30 с 0,8 / до середины 0,3 / позже 0,1; дослушал 0,2 / 0,4 «новое»; ручной запуск 0,5) и полураспадом 90 дней; вкус — байесовская логистическая регрессия; контекст — уровни «время суток → × сезон → × погода» с откатом λ = n/(n + 20) (компонент `context` в оценке); «не сейчас» учит только контекст своего ведра; «никогда» — вкус (0,5) + жёсткая маска; сессия — вектор с полураспадом 10 мин (пропуск −0,15, лайк +0,10). Настройки → «Моя волна». Тесты сигналов + smoke «выкл. — волна играет, сброс работает»

- [x] T3.29 «Почему этот трек» (`14` §17, FR-LEARN-009): движок помнит вклады компонентов последней пересборки; для трека — 1–2 наибольших над средним по кандидатам + «новое для вас» / «давно не слушали»; формулировки — шаблоны `wave.why.*` («Вы отметили его ♡», «Похоже на ваш любимый жанр — рок и метал», «Такое вы часто слушаете вечером», «Похоже на то, что нравится вам сейчас»). В «⋯» плеера, когда играет волна. Тесты + smoke
