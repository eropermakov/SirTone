# Спайк S-20 — заголовок окна и Mica

- **Дата:** 2026-10-16, Этап 0 · **Требование:** FR-SHELL-008 · **ADR:** D-60 · **Задача:** T0.23
- **Вопрос:** как получить заголовок по `DESIGN.md` §7/§11 (системные кнопки, перетаскивание, Snap Layouts, цвет `bg-base`) в Tauri 2 на Windows.

## 1. Варианты
| Вариант | Кнопки и Snap Layouts | Цена | Итог |
|---|---|---|---|
| **(а) родной заголовок, окрашенный DWM** (`DWMWA_CAPTION_COLOR`, `DWMWA_TEXT_COLOR`, `DWMWA_BORDER_COLOR`, `DWMWA_USE_IMMERSIVE_DARK_MODE`) | настоящие системные — Snap Layouts, Alt+пробел, двойной клик, доступность работают без кода | ~60 строк, без зависимостей (`windows` уже в реестре) | **выбран** |
| (б) `decorations: false` + свои кнопки (`tauri-plugin-decorum`) | имитация; Snap Layouts — через перехват `WM_NCHITTEST` | новая зависимость, риск расхождения с системой на 100–200 % DPI | не нужен |
| Mica (`setEffects` + `transparent: true`) | — | прозрачное окно ломает «без белой вспышки» (фон рисует страница), а `DESIGN.md` §11 допускает «иначе сплошной цвет» | отложено |

## 2. Реализация
- `crates/sirtone-platform/src/caption.rs` — `apply(hwnd, dark)`: цвета из токенов `DESIGN.md` §3 (`bg-base` #161111 / #f2eee6, `text-primary` #f9f6f0 / #1c1616).
- `apps/desktop/src-tauri/src/window_chrome.rs` — при старте по теме ОС; команда `window_set_theme(dark)` — UI вызывает её при каждой смене темы (в т.ч. «Как в системе» при смене темы Windows).
- Заголовок окна — «Сиртон».

## 3. Проверка (захват окна с рамкой через `PrintWindow`, без рук)
| Тема | Пиксель заголовка | Ожидалось |
|---|---|---|
| Тёмная (тема ОС) | `#161111` | `bg-base` тёмной ✅ |
| Светлая (переключено в приложении) | `#f2eee6` | `bg-base` светлой ✅ |

Снимки: `img/s20-caption-dark.png`, `img/s20-caption-light.png` — заголовок сливается с сайдбаром, как в `DESIGN.md` §7.

## 4. Ограничения
- Windows 10 не поддерживает цвет заголовка — там остаётся системный тёмный/светлый (`DWMWA_USE_IMMERSIVE_DARK_MODE`).
- Mica не включена: вернуться, если владелец захочет именно эффект Mica (нужны прозрачное окно и проверка белой вспышки).
- Snap Layouts и DPI 100–200 % не требуют проверки — кнопки системные; на устройстве владельца достаточно навести на «развернуть».
